# Technology Stack: Missing Semester

## Backend and Site Generation
- **Ruby (v3.1.2):** Primary language for Jekyll and dependency management.
- **Jekyll (v3.9.2):** Static site generator used to build and serve the project.
- **Bundler:** Manages Ruby gems and ensures consistent environments across machines.

## Frontend
- **Liquid:** The templating language used for Jekyll's site structure.
- **Vanilla CSS:** Standard CSS for styling, without any additional pre-processors.
- **Kramdown/GFM:** The flavor of Markdown used for lecture content and documentation.

## Infrastructure and Tooling
- **Docker/Docker Compose:** Provides a consistent development environment without requiring local Ruby installation.
- **GitHub Actions:** Manages the build and deployment process (CI/CD) and checks for broken links.
- **Git:** Standard version control for the project.
