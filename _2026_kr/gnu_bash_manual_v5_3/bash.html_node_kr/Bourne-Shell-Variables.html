5.1 Bourne 쉘 변수 ¶

Bash는 특정 쉘 변수들을 Bourne 쉘과 동일한 방식으로 사용합니다. 일부 경우, Bash는 변수에 기본값을 할당합니다.

CDPATH ¶

cd 빌트인 명령어를 위한 검색 경로로 사용되는 콜론(:)으로 구분된 디렉토리 목록입니다.

HOME ¶

현재 사용자의 홈 디렉토리입니다. cd 빌트인 명령어의 기본 인자입니다. 이 변수의 값은 물결표 확장(물결표 확장 참조)에서도 사용됩니다.

IFS ¶

필드를 구분하는 문자들의 목록입니다. 확장의 일부로 단어를 분할할 때와 read 빌트인이 줄을 여러 단어로 분할할 때 사용됩니다. 단어 분할에 대한 설명은 단어 분할을 참조하십시오.

MAIL ¶

이 값이 파일명이나 디렉토리 이름으로 설정되어 있고 MAILPATH 변수가 설정되어 있지 않다면, Bash는 지정된 파일이나 Maildir 형식의 디렉토리에 새로운 메일이 도착했음을 사용자에게 알립니다.

MAILPATH ¶

쉘이 주기적으로 새 메일을 확인하는 파일명들의 콜론 구분 목록입니다. 각 목록 항목은 파일 이름 뒤에 ‘?’를 붙여 새 메일 도착 시 출력할 메시지를 지정할 수 있습니다. 메시지 텍스트 내에서 $_은 현재 메일 파일의 이름으로 확장됩니다.

OPTARG ¶

getopts 빌트인에 의해 가장 최근에 처리된 옵션 인자의 값입니다.

OPTIND ¶

getopts 빌트인에 의해 다음에 처리될 인자의 인덱스입니다.

PATH ¶

쉘이 명령어를 찾을 디렉토리들의 콜론 구분 목록입니다. PATH 값 내의 길이가 0인(null) 디렉토리 이름은 현재 디렉토리를 나타냅니다. null 디렉토리 이름은 두 개의 인접한 콜론으로 나타나거나, 시작 또는 마지막의 콜론으로 나타날 수 있습니다. 기본 경로는 시스템마다 다르며, bash를 설치하는 관리자에 의해 설정됩니다. 흔히 사용되는 값은 "/usr/local/bin:/usr/local/sbin:/usr/bin:/usr/sbin:/bin:/sbin"입니다.

PS1 ¶

기본 프롬프트 문자열입니다. 기본값은 ‘\s-\v\$ ’입니다. PS1이 표시되기 전 확장되는 이스케이프 시퀀스들의 전체 목록은 프롬프트 제어하기를 참조하십시오.

PS2 ¶

보조 프롬프트 문자열입니다. 기본값은 ‘> ’입니다. PS2는 표시되기 전 PS1과 동일한 방식으로 확장됩니다.
