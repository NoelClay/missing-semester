8.8 프로그래밍 가능한 자동 완성 예시 ¶

complete 및 compgen이 제공하는 기본 액션들을 넘어 추가적인 자동 완성 기능을 얻는 가장 흔한 방법은 쉘 함수를 사용하고 complete -F를 사용하여 특정 명령어에 바인딩하는 것입니다.

다음 함수는 cd 빌트인 명령어를 위한 자동 완성 기능을 제공합니다. 이는 자동 완성을 위해 사용되는 쉘 함수가 무엇을 해야 하는지 보여주는 아주 좋은 예시입니다. 이 함수는 $2로 전달된 단어를 사용하여 완성할 디렉토리 이름을 결정합니다. COMP_WORDS 배열 변수를 사용할 수도 있으며, 현재 단어는 COMP_CWORD 변수에 의해 인덱싱됩니다.

이 함수는 작업의 상당 부분을 complete 및 compgen 빌트인에 의존하며, 기본적인 디렉토리 이름을 받아들이는 것 외에 Bash의 cd가 수행하는 추가적인 기능들만 더합니다: 물결표 확장(물결표 확장 참조), 위에서 설명한 $CDPATH 내의 디렉토리 검색(Bourne 쉘 빌트인 참조), 그리고 cdable_vars 쉘 옵션에 대한 기본적인 지원(Shopt 빌트인 참조)이 그것입니다. _comp_cd는 공백이나 탭이 포함된 파일 이름을 수용하기 위해 IFS의 값을 줄바꿈(newline)만 포함하도록 수정합니다 – compgen은 생성한 자동 완성 후보들을 한 줄에 하나씩 출력하기 때문입니다.

가능한 자동 완성 후보들은 COMPREPLY 배열 변수에 배열 요소당 하나씩 들어갑니다. 프로그래밍 가능한 자동 완성 시스템은 함수가 반환될 때 해당 변수로부터 완성 후보들을 가져옵니다. 

# cd 빌트인을 위한 자동 완성 함수
# bash_completion 패키지의 cd 완성 함수를 기반으로 함
_comp_cd()
{
    local IFS=$' \t\n'    # IFS 정규화
    local cur _skipdot _cdpath
    local i j k

    # 물결표 확장 (물결표를 전체 경로명으로 확장함)
    case "$2" in
    \~*)    eval cur="$2" ;;
    *)      cur=$2 ;;
    esac

    # cdpath가 없거나 절대 경로인 경우 -- 일반적인 디렉토리 완성 수행
    if [[ -z "${CDPATH:-}" ]] || [[ "$cur" == @(./*|../*|/*) ]]; then
        # compgen은 경로를 한 줄에 하나씩 출력함; while 루프를 사용할 수도 있음
        IFS=$'\n'
        COMPREPLY=( $(compgen -d -- "$cur") )
        IFS=$' \t\n'
    # CDPATH 검색 + CDPATH에 없는 경우 현재 디렉토리의 디렉토리들 검색
    else
        IFS=$'\n'
        _skipdot=false
        # CDPATH를 전처리하여 빈 디렉토리 이름을 .으로 변환
        _cdpath=${CDPATH/#:/.:}
        _cdpath=${_cdpath//::/:.:}
        _cdpath=${_cdpath/%:/:.}
        for i in ${_cdpath//:/$'\n'}; do
            if [[ $i -ef . ]]; then _skipdot=true; fi
            k="${#COMPREPLY[@]}"
            for j in $( compgen -d -- "$i/$cur" ); do
                COMPREPLY[k++]=${j#$i/}        # 디렉토리 부분 잘라내기
            done
        done
        $_skipdot || COMPREPLY+=( $(compgen -d -- "$cur") )
        IFS=$' \t\n'
    fi

    # 적절한 쉘 옵션이 설정되어 있고 완성 후보가 없는 경우 변수 이름 검색
    if shopt -q cdable_vars && [[ ${#COMPREPLY[@]} -eq 0 ]]; then
        COMPREPLY=( $(compgen -v -- "$cur") )
    fi

    return 0
}

우리는 complete의 -F 옵션을 사용하여 자동 완성 함수를 설치합니다: 

# Readline이 적절하게 인용 처리를 하고 디렉토리 뒤에 슬래시를 붙이도록 지시;
# 다른 인자들에 대해서는 bash 기본 자동 완성을 사용
complete -o filenames -o nospace -o bashdefault -F _comp_cd cd

Bash와 Readline이 세부 사항 중 일부를 대신 처리해주길 원하므로, 몇 가지 다른 옵션들을 사용하여 Bash와 Readline이 무엇을 해야 할지 알려줍니다. -o filenames 옵션은 Readline에 가능한 자동 완성 후보들을 파일 이름으로 취급하고 적절하게 인용 처리하라고 지시합니다. 또한 이 옵션은 Readline이 디렉토리로 판단되는 파일 이름 뒤에 슬래시를 붙이게 만듭니다(이것이 우리가 _comp_cd를 확장하여 CDPATH를 통해 찾은 디렉토리를 사용할 때 슬래시를 붙이고 싶어 하는 이유입니다: Readline은 해당 후보들이 디렉토리인지 알 수 없기 때문입니다). -o nospace 옵션은 우리가 디렉토리 이름 뒤에 무언가를 덧붙이고 싶을 경우를 대비해 Readline이 디렉토리 이름 뒤에 공백 문자를 붙이지 않도록 지시합니다. -o bashdefault 옵션은 “Bash 기본” 자동 완성의 나머지를 가져옵니다 – 이는 Bash가 기본 Readline 세트에 추가하는 가능한 자동 완성 후보들입니다. 여기에는 명령어 이름 완성, ‘$’ 또는 ‘${’로 시작하는 단어에 대한 변수 완성, 경로명 확장 패턴을 포함하는 완성(파일 이름 확장 참조) 등이 포함됩니다.

complete를 사용하여 설치하고 나면, 우리가 cd 명령어에 대해 단어 완성을 시도할 때마다 _comp_cd가 호출될 것입니다.

대부분의 일반적인 GNU, Unix, 및 Linux 명령어들에 대한 방대한 자동 완성 모음인 더 많은 예시들은 bash_completion 프로젝트의 일부로 제공됩니다. 이는 많은 GNU/Linux 배포판에 기본적으로 설치되어 있습니다. 원래 Ian Macdonald에 의해 작성되었으며, 현재는 https://github.com/scop/bash-completion/에서 프로젝트가 유지되고 있습니다. Solaris 및 Mac OS X와 같은 다른 시스템을 위한 포트(ports)들도 존재합니다.

bash_completion 패키지의 이전 버전은 Bash와 함께 examples/complete 하위 디렉토리에 배포됩니다.
