6.1 Bash 호출하기 ¶

bash [long-opt] [-ir] [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] [argument ...]
bash [long-opt] [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] -c string [argument ...]
bash [long-opt] -s [-abefhkmnptuvxdBCDHP] [-o option]
    [-O shopt_option] [argument ...]

set 빌트인에서 사용되는 모든 단일 문자 옵션들은(Set 빌트인 참조) 쉘 호출 시 옵션으로 사용될 수 있습니다. 또한, 사용할 수 있는 여러 다중 문자(multi-character) 옵션들이 있습니다. 이러한 옵션들은 인식되려면 반드시 명령줄에서 단일 문자 옵션들보다 먼저 나타나야 합니다.

--debugger

쉘이 시작되기 전에 디버거 프로파일을 실행하도록 준비합니다. 확장 디버깅 모드를 켭니다(shopt 빌트인의 extdebug 옵션 설명은 Shopt 빌트인 참조).

--dump-po-strings

앞에 ‘$’가 붙은 모든 큰따옴표 문자열 목록을 GNU gettext PO (portable object) 파일 형식으로 표준 출력에 출력합니다. 출력 형식을 제외하고는 -D 옵션과 동일합니다.

--dump-strings

-D와 동일합니다.

--help

표준 출력에 사용법 메시지를 표시하고 성공적으로 종료합니다.

--init-file filename
--rcfile filename

대화형 쉘에서 (~/.bashrc 대신) filename으로부터 명령어들을 실행합니다.

--login

-l과 동일합니다.

--noediting

대화형 쉘일 때 명령줄을 읽기 위해 GNU Readline 라이브러리(명령줄 편집 참조)를 사용하지 않습니다.

--noprofile

Bash가 로그인 쉘로 호출될 때 시스템 전체 시작 파일인 /etc/profile이나 개인 초기화 파일들인 ~/.bash_profile, ~/.bash_login, 또는 ~/.profile을 로드하지 않습니다.

--norc

대화형 쉘에서 ~/.bashrc 초기화 파일을 읽지 않습니다. 쉘이 sh로 호출된 경우에는 이 옵션이 기본적으로 켜집니다.

--posix

POSIX 모드를 활성화합니다. 기본 동작이 POSIX 표준과 다른 부분에서 표준에 맞게 Bash의 동작을 변경합니다. 이는 Bash가 해당 표준의 엄격한 슈퍼셋(superset)으로 동작하도록 하기 위함입니다. Bash POSIX 모드에 대한 설명은 Bash와 POSIX를 참조하십시오.

--restricted

-r과 동일합니다. 쉘을 제한된 쉘(restricted shell)로 만듭니다(제한된 쉘 참조).

--verbose

-v와 동일합니다. 쉘 입력 줄을 읽어들이는 대로 출력합니다.

--version

표준 출력에 이 Bash 인스턴스의 버전 정보를 표시하고 성공적으로 종료합니다.

호출 시 제공할 수 있는 몇 가지 단일 문자 옵션들이 있는데, 이들은 set 빌트인에서는 사용할 수 없는 것들입니다.

-c

첫 번째 비-옵션 인자인 command_string으로부터 명령어들을 읽어 실행한 뒤 종료합니다. command_string 뒤에 인자들이 있다면, 첫 번째 인자는 $0에 할당되고 나머지 인자들은 위치 파라미터들에 할당됩니다. $0에 할당된 값은 경고 및 에러 메시지에서 사용될 쉘의 이름이 됩니다.

-i

쉘이 대화형(interactively)으로 실행되도록 강제합니다. 대화형 쉘에 대한 설명은 대화형 쉘을 참조하십시오.

-l

이 쉘이 로그인에 의해 직접 호출된 것처럼 동작하게 합니다. 대화형 쉘인 경우, 이는 ‘exec -l bash’로 로그인 쉘을 시작하는 것과 동일합니다. 비대화형 쉘인 경우, 로그인 쉘 시작 파일들을 읽어 실행합니다. ‘exec bash -l’ 또는 ‘exec bash --login’은 현재 쉘을 Bash 로그인 쉘로 대체합니다. 로그인 쉘의 특별한 동작에 대한 설명은 Bash 시작 파일을 참조하십시오.

-r

쉘을 제한된 쉘(restricted shell)로 만듭니다(제한된 쉘 참조).

-s

이 옵션이 있거나 옵션 처리 후 인자가 남아있지 않다면, Bash는 표준 입력으로부터 명령어들을 읽습니다. 이 옵션은 대화형 쉘을 호출할 때나 파이프를 통해 입력을 읽을 때 위치 파라미터를 설정할 수 있게 해줍니다.

-D

앞에 ‘$’가 붙은 모든 큰따옴표 문자열 목록을 표준 출력에 출력합니다. 이 문자열들은 현재 로케일이 C나 POSIX가 아닐 때 언어 번역의 대상이 되는 문자열들입니다(로케일 특정 번역 참조). 이 옵션은 -n 옵션을 내포하며, 명령어는 실행되지 않습니다.

[-+]O [shopt_option]

shopt_option은 shopt 빌트인에서 허용되는 쉘 옵션 중 하나입니다(Shopt 빌트인 참조). shopt_option이 있으면, -O는 해당 옵션의 값을 설정하고 +O는 해제합니다. 만약 shopt_option이 제공되지 않으면, Bash는 shopt이 허용하는 쉘 옵션들의 이름과 값을 표준 출력에 출력합니다. 호출 옵션이 +O인 경우, 출력은 입력으로 재사용할 수 있는 형식으로 표시됩니다.

--

--는 옵션의 끝을 알리며 추가적인 옵션 처리를 중단합니다. -- 뒤의 모든 인자들은 쉘 스크립트 파일명과 해당 스크립트로 전달될 인자들로 취급됩니다(쉘 스크립트 참조).

-

--와 동일합니다.

로그인 쉘(login shell)이란 0번 인자의 첫 번째 문자가 ‘-’이거나 --login 옵션과 함께 호출된 쉘을 말합니다.

대화형 쉘(interactive shell)이란 비-옵션 인자 없이 시작된 쉘(단, -s가 지정된 경우는 제외), -c 옵션 없이 시작된 쉘, 그리고 표준 입력과 표준 에러가 모두 (isatty(3)에 의해 결정된 대로) 터미널에 연결된 쉘, 또는 -i 옵션과 함께 시작된 쉘을 말합니다. 더 자세한 정보는 대화형 쉘을 참조하십시오.

옵션 처리 후 인자가 남아있고 -c 나 -s 옵션이 제공되지 않았다면, 첫 번째 인자는 쉘 명령어들을 포함한 파일 이름으로 취급됩니다(쉘 스크립트 참조). Bash가 이런 방식으로 호출되면 $0은 해당 파일 이름으로 설정되고, 위치 파라미터들은 나머지 인자들로 설정됩니다. Bash는 이 파일로부터 명령어들을 읽어 실행한 뒤 종료합니다. Bash의 종료 상태는 스크립트에서 마지막으로 실행된 명령어의 종료 상태가 됩니다. 실행된 명령어가 없다면 종료 상태는 0입니다. Bash는 먼저 현재 디렉토리에서 파일을 열려고 시도하고, 파일을 찾지 못하면 PATH에 있는 디렉토리들에서 해당 스크립트를 검색합니다.
