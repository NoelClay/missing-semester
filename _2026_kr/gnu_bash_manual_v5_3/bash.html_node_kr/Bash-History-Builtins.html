9.2 Bash 히스토리 빌트인 ¶

Bash는 히스토리 목록과 히스토리 파일을 조작하는 두 가지 빌트인 명령어를 제공합니다.

fc ¶
fc [-e ename] [-lnr] [first] [last]
fc -s [pat=rep] [command]

첫 번째 형식은 히스토리 목록에서 first부터 last까지의 명령어 범위를 선택하여 표시하거나 편집한 후 다시 실행합니다. first와 last는 모두 문자열(해당 문자열로 시작하는 가장 최근 명령어를 찾기 위해) 또는 숫자(히스토리 목록의 인덱스이며, 음수는 현재 명령어 번호로부터의 오프셋으로 사용됨)로 지정할 수 있습니다.

목록을 나열할 때, first 또는 last가 0이면 -1과 동일하고, -0은 현재 명령어(보통 fc 명령어)와 동일합니다; 그 외의 경우 0은 -1과 동일하고 -0은 유효하지 않습니다.

만약 last가 지정되지 않으면, 목록 나열 시에는 현재 명령어로 설정되고 그 외의 경우에는 first로 설정됩니다. 만약 first가 지정되지 않으면, 편집 시에는 이전 명령어로 설정되고 목록 나열 시에는 −16으로 설정됩니다.

-l 플래그가 제공되면 명령어들이 표준 출력으로 나열됩니다. -n 플래그는 목록 나열 시 명령어 번호를 표시하지 않도록 합니다. -r 플래그는 목록의 순서를 역순으로 바꿉니다.

그렇지 않은 경우, fc는 해당 명령어들이 포함된 파일에 대해 ename으로 명명된 에디터를 호출합니다. ename이 제공되지 않으면 fc는 다음 변수 확장 값을 사용합니다: ${FCEDIT:-${EDITOR:-vi}}. 이는 FCEDIT 변수가 설정되어 있으면 그 값을 사용하고, 그렇지 않고 EDITOR 변수가 설정되어 있으면 그 값을 사용하며, 둘 다 설정되어 있지 않으면 vi를 사용함을 의미합니다. 편집이 완료되면 fc는 편집된 명령어가 포함된 파일을 읽어 들여 이를 에코(echo)하고 실행합니다.

두 번째 형식에서 fc는 선택된 명령어에서 pat이 나타나는 모든 부분을 rep으로 교체한 뒤 command를 다시 실행합니다. command는 위에서 설명한 first와 동일하게 해석됩니다.

fc 명령어와 함께 사용하기 유용한 별칭은 r='fc -s'입니다. 이렇게 하면 ‘r cc’를 입력하여 cc로 시작하는 마지막 명령어를 실행하거나, ‘r’을 입력하여 마지막 명령어를 다시 실행할 수 있습니다(별칭 참조).

첫 번째 형식이 사용된 경우, 잘못된 옵션을 만나거나 first 또는 last가 범위를 벗어난 히스토리 줄을 지정하지 않는 한 반환 값은 0입니다. 명령어 파일을 편집하고 다시 실행하는 경우, 반환 값은 실행된 마지막 명령어의 값이며, 임시 파일 작업 중 에러가 발생하면 실패를 반환합니다. 두 번째 형식이 사용된 경우, 반환 상태는 다시 실행된 명령어의 상태입니다. 단, command가 유효한 히스토리 항목을 지정하지 않는 경우 fc는 0이 아닌 상태를 반환합니다.

history ¶
history [n]
history -c
history -d offset
history -d start-end
history [-anrw] [filename]
history -ps arg

옵션 없이 사용하면 번호와 함께 히스토리 목록을 표시합니다. ‘*’ 접두사가 붙은 항목은 수정된 항목입니다. 인자 n은 마지막 n개의 항목만 나열하도록 합니다. 쉘 변수 HISTTIMEFORMAT이 설정되어 있고 null이 아니라면, 표시되는 각 히스토리 항목과 연관된 타임스탬프를 표시하기 위해 strftime(3)의 형식 문자열로 사용됩니다. history가 HISTTIMEFORMAT을 사용하는 경우, 형식화된 타임스탬프와 히스토리 항목 사이에 별도의 공백을 출력하지 않습니다.

제공되는 경우 옵션들은 다음과 같은 의미를 갖습니다:

-c

히스토리 목록을 모두 비웁니다. 다른 옵션들과 결합하여 히스토리 목록을 교체하는 데 사용될 수 있습니다.

-d offset

offset 위치의 히스토리 항목을 삭제합니다. offset이 양수이면 히스토리가 표시될 때 나타나는 번호대로 지정해야 합니다. offset이 음수이면 마지막 히스토리 위치보다 하나 더 큰 위치를 기준으로 상대적인 위치로 해석되므로, 음수 인덱스는 히스토리 끝에서부터 거꾸로 세며 인덱스 ‘-1’은 현재의 history -d 명령어를 가리킵니다.

-d start-end

start부터 end까지(해당 위치 포함)의 히스토리 항목 범위를 삭제합니다. start와 end의 양수 및 음수 값은 위에서 설명한 대로 해석됩니다.

-a

“새로운” 히스토리 줄들을 히스토리 파일에 덧붙입니다. 이는 현재 Bash 세션 시작 이후 입력되었지만 아직 히스토리 파일에 덧붙여지지 않은 히스토리 줄들입니다.

-n

히스토리 파일로부터 아직 읽어 들이지 않은 히스토리 줄들을 읽어 현재 히스토리 목록에 추가합니다. 이는 현재 Bash 세션 시작 이후 히스토리 파일에 덧붙여진 줄들입니다.

-r

히스토리 파일을 읽어 그 내용을 히스토리 목록 끝에 덧붙입니다.

-w

현재 히스토리 목록을 히스토리 파일에 기록하여 히스토리 파일을 덮어씁니다.

-p

arg들에 대해 히스토리 치환(history substitution)을 수행하고 결과를 표준 출력에 표시합니다. 결과는 히스토리 목록에 저장되지 않습니다.

-s

arg들을 단일 항목으로 히스토리 목록 끝에 추가합니다. arg들을 추가하기 전에 히스토리 목록의 마지막 명령어가 제거됩니다.

-w, -r, -a, 또는 -n 옵션 중 하나와 함께 filename 인자가 제공되면, Bash는 filename을 히스토리 파일로 사용합니다. 그렇지 않은 경우 HISTFILE 변수의 값을 사용합니다. HISTFILE이 해제되어 있거나 null인 경우 이러한 옵션들은 효과가 없습니다.

만약 HISTTIMEFORMAT 변수가 설정되어 있다면, history는 위에서 설명한 대로 히스토리 주석 문자와 함께 각 히스토리 항목과 연관된 타임스탬프 정보를 히스토리 파일에 기록합니다. 히스토리 파일을 읽을 때, 히스토리 주석 문자로 시작하고 바로 뒤에 숫자가 오는 줄은 그 뒤에 오는 히스토리 항목의 타임스탬프로 해석됩니다.

반환 값은 잘못된 옵션을 만나거나, 히스토리 파일을 읽거나 쓰는 중에 에러가 발생하거나, -d의 인자로 잘못된 offset이나 범위가 제공되거나, -p의 인자로 제공된 히스토리 확장이 실패하지 않는 한 0입니다.
