3.5.8 파일 이름 확장 ¶

단어 분할이 완료된 후, -f 옵션(Set 빌트인 참조)이 설정되어 있지 않은 한 Bash는 각 단어에서 ‘*’, ‘?’, 그리고 ‘[’ 문자가 있는지 검사합니다. 만약 이러한 문자들 중 하나가 인용되지 않은 상태로 나타나면, 해당 단어는 패턴(pattern)으로 간주되어 그 패턴과 매치되는 파일 이름들의 정렬된 목록으로 대체됩니다(패턴 매칭 참조). 정렬 방식은 GLOBSORT 쉘 변수의 값에 따릅니다(Bash 변수 참조).

매치되는 파일 이름을 찾지 못했고 nullglob 쉘 옵션이 비활성화되어 있다면, 해당 단어는 수정되지 않고 그대로 남습니다. 만약 nullglob 옵션이 설정되어 있는데 매치되는 파일이 없다면, 해당 단어는 제거됩니다. 만약 failglob 쉘 옵션이 설정되어 있는데 매치되는 파일이 없다면, Bash는 에러 메시지를 출력하고 명령어를 실행하지 않습니다. 만약 nocaseglob 쉘 옵션이 활성화되어 있으면, 알파벳 문자의 대소문자를 구분하지 않고 매칭을 수행합니다.

파일 이름 확장에 패턴이 사용될 때, 파일 이름의 시작 부분이나 슬래시 바로 뒤에 오는 ‘.’ 문자는 dotglob 쉘 옵션이 설정되어 있지 않은 한 반드시 명시적으로 매치되어야 합니다. . 및 .. 파일 이름을 매치하려면 dotglob이 설정되어 있더라도 패턴이 ‘.’으로 시작해야 합니다(예: ‘.?’). 만약 globskipdots 쉘 옵션이 활성화되어 있으면, 패턴이 ‘.’으로 시작하더라도 . 및 .. 파일 이름은 절대 매치되지 않습니다. 파일 이름을 매칭하는 상황이 아닐 때는 ‘.’ 문자가 특별하게 취급되지 않습니다.

파일 이름을 매칭할 때 슬래시(/) 문자는 항상 패턴 내의 슬래시에 의해 명시적으로 매치되어야 하지만, 다른 매칭 컨텍스트에서는 아래에 설명된 특수 패턴 문자에 의해 매치될 수 있습니다(패턴 매칭 참조).

nocaseglob, nullglob, globskipdots, failglob, 그리고 dotglob 옵션에 대한 설명은 Shopt 빌트인의 shopt 설명을 참조하십시오.

GLOBIGNORE 쉘 변수를 사용하여 패턴과 매치되는 파일 이름 집합을 제한할 수 있습니다. GLOBIGNORE가 설정되어 있으면, 매치된 파일 이름 중 GLOBIGNORE 내의 패턴들 중 하나와도 매치되는 각 파일 이름은 매치 목록에서 제거됩니다. 만약 nocaseglob 옵션이 설정되어 있으면 GLOBIGNORE의 패턴에 대한 매칭은 대소문자를 구분하지 않고 수행됩니다. . 및 .. 파일 이름은 GLOBIGNORE가 설정되어 있고 null이 아닐 때 항상 무시됩니다. 하지만 GLOBIGNORE를 null이 아닌 값으로 설정하면 dotglob 쉘 옵션을 활성화하는 효과가 있으므로, ‘.’으로 시작하는 다른 모든 파일 이름들은 매치됩니다. ‘.’으로 시작하는 파일 이름들을 무시하는 예전 방식을 유지하려면 ‘.*’을 GLOBIGNORE의 패턴 중 하나로 포함시키십시오. dotglob 옵션은 GLOBIGNORE가 해제(unset)될 때 비활성화됩니다. GLOBIGNORE 패턴 매칭은 extglob 쉘 옵션 설정을 따릅니다.

GLOBSORT 쉘 변수의 값은 아래 설명된 대로 경로명 확장 결과가 정렬되는 방식을 제어합니다(Bash 변수 참조).
