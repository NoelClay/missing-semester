3.4 쉘 파라미터 ¶

파라미터(parameter)는 값을 저장하는 엔티티입니다. 이는 이름(name), 숫자, 또는 아래 나열된 특수 문자 중 하나일 수 있습니다. 변수(variable)는 이름으로 지칭되는 파라미터입니다. 변수는 값(value)과 0개 이상의 속성(attributes)을 가집니다. 속성은 declare 빌트인 명령어를 사용하여 할당합니다(Bash 빌트인 명령어의 declare 빌트인 설명 참조). export 및 readonly 빌트인도 특정 속성들을 할당합니다.

파라미터에 값이 할당되어 있으면 해당 파라미터는 설정된(set) 상태입니다. 빈 문자열(null string)도 유효한 값입니다. 한번 설정된 변수는 unset 빌트인 명령어를 사용해야만 해제(unset)할 수 있습니다.

변수는 다음과 같은 형식의 문장을 사용하여 값을 할당합니다: 

name=[value]

만약 value가 주어지지 않으면 변수에는 빈 문자열이 할당됩니다. 모든 값들은 물결표 확장, 파라미터 및 변수 확장, 명령어 치환, 산술 확장 및 따옴표 제거 과정을 거칩니다(쉘 파라미터 확장 참조). 만약 변수에 integer(정수) 속성이 설정되어 있다면, $((…)) 확장을 사용하지 않더라도 value는 산술식으로 평가됩니다(산술 확장 참조). 단어 분할과 파일 이름 확장은 수행되지 않습니다. 할당문은 alias, declare, typeset, export, readonly, 그리고 local 빌트인 명령어(선언 명령어)의 인자로 나타날 수도 있습니다. POSIX 모드(Bash와 POSIX 참조)일 때, 이들 빌트인은 command 빌트인 뒤에 하나 이상 나타날 수 있으며 이러한 할당문 속성을 유지합니다. 예를 들어: 

command export var=value

쉘 변수나 배열 인덱스(배열 참조)에 값을 할당하는 할당문 컨텍스트에서, ‘+=’ 연산자는 변수의 이전 값에 덧붙이거나(append) 더합니다(add). 여기에는 할당문을 허용하는 declare와 같은 선언 명령어의 인자들도 포함됩니다. integer 속성이 설정된 변수에 ‘+=’를 적용하면, 변수의 현재 값과 value가 각각 산술식으로 평가되고 그 결과의 합이 변수의 값으로 할당됩니다. 현재 값은 보통 정수 상수이지만 산술식일 수도 있습니다. 배열 변수에 복합 할당(배열 참조)을 사용하여 ‘+=’를 적용하면, 변수의 값은 (‘=’를 사용할 때처럼) 해제되지 않으며, 새로운 값들은 배열의 최대 인덱스보다 1 큰 위치부터 추가되거나(인덱스 배열의 경우), 연관 배열(associative array)에서는 추가적인 키-값 쌍으로 더해집니다. 문자열 값을 가진 변수에 적용하면, value가 확장되어 변수의 값 뒤에 덧붙여집니다.

declare 또는 local 빌트인 명령어의 -n 옵션을 사용하여 변수에 nameref 속성을 할당하면, 네임레프(nameref), 즉 다른 변수에 대한 참조를 생성할 수 있습니다. 이를 통해 변수를 간접적으로 조작할 수 있습니다. 네임레프 변수를 참조하거나, 할당하거나, 해제하거나, 혹은 속성을 수정할 때마다(네임레프 속성 자체를 사용하거나 변경하는 경우는 제외), 해당 작업은 실제로는 네임레프 변수의 값이 가리키는 변수에 대해 수행됩니다. 네임레프는 쉘 함수 내에서 함수 인자로 전달된 이름을 가진 변수를 참조하는 데 흔히 사용됩니다. 예를 들어, 변수 이름이 함수의 첫 번째 인자로 전달된 경우, 함수 내부에서 

declare -n ref=$1

을 실행하면 값이 첫 번째 인자로 전달된 변수 이름인 지역 네임레프 변수 ref가 생성됩니다. ref에 대한 참조 및 할당, 그리고 속성 변경은 $1로 이름이 전달된 변수에 대한 참조, 할당 및 속성 수정으로 취급됩니다.

for 루프의 제어 변수에 네임레프 속성이 있는 경우, 단어 목록은 쉘 변수들의 목록이 될 수 있으며, 루프가 실행될 때 목록의 각 단어에 대해 차례대로 이름 참조가 수립됩니다. 배열 변수에는 네임레프 속성을 부여할 수 없습니다. 하지만 네임레프 변수는 배열 변수와 서브스크립트가 붙은 배열 변수를 참조할 수 있습니다. 네임레프는 unset 빌트인의 -n 옵션을 사용하여 해제할 수 있습니다(Bourne 쉘 빌트인 참조). 그렇지 않고 네임레프 변수의 이름을 인자로 하여 unset을 실행하면, 네임레프 변수가 참조하는 변수가 해제됩니다.

쉘이 시작될 때 환경(environment)을 읽어 들이고, 아래에 설명된 대로 유효한 이름을 가진 각 환경 변수로부터 쉘 변수를 생성합니다(환경 참조).
