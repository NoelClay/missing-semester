8 명령줄 편집 (Command Line Editing) ¶

이 장에서는 GNU 명령줄 편집 인터페이스의 기본 기능들에 대해 설명합니다. 명령줄 편집 기능은 Readline 라이브러리에 의해 제공되며, 이 라이브러리는 Bash를 포함한 여러 다른 프로그램들에서도 사용됩니다. 명령줄 편집 기능은 대화형 쉘을 사용할 때 기본적으로 활성화되어 있으며, 쉘 호출 시 --noediting 옵션을 사용하면 비활성화할 수 있습니다. 라인 편집 기능은 read 빌트인 명령어의 -e 옵션을 사용할 때도 사용됩니다(Bash 빌트인 명령어 참조). 기본적으로 라인 편집 명령어들은 Emacs의 명령어들과 유사하며, vi 스타일의 라인 편집 인터페이스도 사용할 수 있습니다. 라인 편집 기능은 set 빌트인 명령어의 -o emacs 또는 -o vi 옵션을 사용하여 언제든지 활성화할 수 있으며(Set 빌트인 참조), set의 +o emacs 또는 +o vi 옵션을 사용하여 비활성화할 수 있습니다.
