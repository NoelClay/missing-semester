4.4 특수 빌트인 (Special Builtins) ¶

역사적인 이유로, POSIX 표준은 여러 빌트인 명령어들을 특수(special) 빌트인으로 분류했습니다. Bash가 POSIX 모드에서 실행 중일 때, 특수 빌트인은 다른 빌트인 명령어들과 세 가지 측면에서 다르게 동작합니다:

  1. 명령어 검색 시 쉘 함수보다 특수 빌트인을 먼저 찾습니다.
  2. 특수 빌트인이 에러 상태를 반환하면, 비대화형 쉘은 종료됩니다.
  3. 명령어 앞에 오는 할당문(assignment statements)은 명령어가 완료된 후에도 쉘 환경에 유지됩니다.

Bash가 POSIX 모드에서 실행 중이 아닐 때, 이 빌트인들은 다른 Bash 빌트인 명령어들과 아무런 차이 없이 동작합니다. Bash POSIX 모드에 대한 설명은 Bash와 POSIX를 참조하십시오.

다음은 POSIX 특수 빌트인 목록입니다: 

break : . source continue eval exec exit export readonly return set
shift times trap unset
