3.1.2.4 ANSI-C 방식 인용 ¶

$'string' 형식의 문자 시퀀스는 특수한 종류의 작은따옴표로 취급됩니다. 이 시퀀스는 string으로 확장되며, 이때 string 내의 백슬래시로 이스케이프된 문자들은 ANSI C 표준에 명시된 대로 치환됩니다. 백슬래시 이스케이프 시퀀스가 있는 경우 다음과 같이 디코딩됩니다:

\a

경고 (벨 소리)

\b

백스페이스

\e
\E

이스케이프 문자 (ANSI C 표준은 아님)

\f

폼 피드(form feed)

\n

줄바꿈 (newline)

\r

캐리지 리턴 (carriage return)

\t

수평 탭

\v

수직 탭

\\

백슬래시

\'

작은따옴표

\"

큰따옴표

\?

물음표

\nnn

팔진수 값 nnn(1~3자리의 팔진수 숫자)을 가지는 8비트 문자.

\xHH

십육진수 값 HH(1~2자리의 십육진수 숫자)를 가지는 8비트 문자.

\uHHHH

십육진수 값 HHHH(1~4자리의 십육진수 숫자)를 가지는 유니코드(ISO/IEC 10646) 문자.

\UHHHHHHHH

십육진수 값 HHHHHHHH(1~8자리의 십육진수 숫자)를 가지는 유니코드(ISO/IEC 10646) 문자.

\cx

제어-x(control-x) 문자.

확장된 결과는 마치 달러 기호($)가 없었던 것처럼 작은따옴표로 감싸진 것으로 취급됩니다.
