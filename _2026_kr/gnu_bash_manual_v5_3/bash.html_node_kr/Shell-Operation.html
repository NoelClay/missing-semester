3.1.1 쉘 동작 방식 ¶

다음은 쉘이 명령어를 읽고 실행할 때의 동작 방식에 대한 간략한 설명입니다. 기본적으로 쉘은 다음 작업을 수행합니다:

  1. 파일(쉘 스크립트 참조), -c 호출 옵션의 인자로 제공된 문자열(Bash 호출하기 참조), 또는 사용자의 터미널에서 입력을 읽습니다.
  2. 인용(Quoting)에 설명된 인용 규칙을 준수하며 입력을 단어(word)와 연산자(operator)로 나눕니다. 이러한 토큰들은 metacharacters(메타 문자)에 의해 구분됩니다. 이 단계에서 별칭 확장(alias expansion, 별칭 참조)이 수행됩니다.
  3. 토큰들을 단순 및 복합 명령어(쉘 명령어 참조)로 파싱합니다.
  4. 다양한 쉘 확장(쉘 확장 참조)을 수행하고, 확장된 토큰들을 파일 이름 목록(파일 이름 확장 참조), 명령어 및 인자들로 나눕니다.
  5. 필요한 리다이렉션(리다이렉션 참조)을 수행하고, 인자 목록에서 리다이렉션 연산자와 해당 피연산자들을 제거합니다.
  6. 명령어를 실행합니다(명령어 실행 참조).
  7. 선택적으로 명령어가 완료될 때까지 기다렸다가 종료 상태(종료 상태 참조)를 수집합니다.
