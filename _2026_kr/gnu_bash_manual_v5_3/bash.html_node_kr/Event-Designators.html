9.3.1 이벤트 지시자 (Event Designators) ¶

이벤트 지시자(event designator)는 히스토리 목록의 특정 항목을 참조하는 수단입니다. 이벤트 지시자는 히스토리 확장 문자로 시작하는 단어의 일부분이며, 단어 지시자가 있는 경우 그 직전까지, 없는 경우 단어의 끝까지를 포함합니다. 참조가 절대적(absolute)이지 않은 한, 이벤트는 히스토리 목록 내의 현재 위치를 기준으로 상대적입니다.

!

히스토리 치환을 시작합니다. 단, 바로 뒤에 공백, 탭, 줄의 끝, ‘=’, 또는 위에서 정의한 다른 쉘 메타 문자가 오는 경우는 제외합니다(정의 참조).

!n

n번째 히스토리 항목을 참조합니다.

!-n

현재 명령어로부터 n만큼 앞선 히스토리 항목을 참조합니다.

!!

바로 이전 항목을 참조합니다. ‘!-1’의 동의어입니다.

!string

히스토리 목록의 현재 위치 이전에서 string으로 시작하는 가장 최근의 명령어를 참조합니다.

!?string[?]

히스토리 목록의 현재 위치 이전에서 string을 포함하는 가장 최근의 명령어를 참조합니다. string 바로 뒤에 줄바꿈이 오는 경우 끝의 ‘?’는 생략할 수 있습니다. string이 생략되면 가장 최근 검색에서 사용했던 문자열을 사용합니다; 이전 검색 문자열이 없다면 에러가 발생합니다.

^string1^string2^

빠른 치환(Quick Substitution). 마지막 명령어를 반복하되, string1을 처음 발견하면 string2로 교체합니다. !!:s^string1^string2^와 동일합니다.

!#

지금까지 입력된 현재 명령줄 전체를 참조합니다.
