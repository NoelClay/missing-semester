8.3 Readline 초기화 파일 ¶

Readline 라이브러리는 기본적으로 Emacs 스타일의 키 바인딩 세트를 제공하지만, 다른 키 바인딩 세트를 사용할 수도 있습니다. 사용자는 관례적으로 홈 디렉토리에 위치하는 inputrc 파일에 명령어들을 넣어 Readline을 사용하는 프로그램들을 커스터마이징할 수 있습니다. 이 파일의 이름은 쉘 변수 INPUTRC의 값으로부터 가져옵니다. 해당 변수가 설정되어 있지 않다면 기본값은 ~/.inputrc입니다. 해당 파일이 존재하지 않거나 읽을 수 없는 경우, Readline은 /etc/inputrc를 찾습니다. bind 빌트인 명령어 또한 Readline 키 바인딩과 변수들을 설정하는 데 사용될 수 있습니다. Bash 빌트인 명령어를 참조하십시오.

Readline 라이브러리를 사용하는 프로그램이 시작될 때, Readline은 초기화 파일을 읽고 그 안에 포함된 모든 변수와 키 바인딩을 설정합니다.

추가적으로, C-x C-r 명령어는 이 초기화 파일을 다시 읽어들여 파일에 가한 모든 변경 사항을 즉시 반영합니다.
