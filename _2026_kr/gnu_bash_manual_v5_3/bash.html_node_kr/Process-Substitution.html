3.5.6 프로세스 치환 ¶

프로세스 치환(Process substitution)은 프로세스의 입력이나 출력을 파일 이름을 사용하여 참조할 수 있게 해줍니다. 형식은 다음과 같습니다: 

<(list)

또는 

>(list)

프로세스 list는 비동기적으로 실행되며, 그 입력이나 출력은 파일 이름으로 나타납니다. 이 파일 이름은 확장의 결과로서 현재 명령어의 인자로 전달됩니다.

만약 >(list) 형식이 사용되면, 해당 파일에 쓰는 내용이 list의 입력이 됩니다. 만약 <(list) 형식이 사용되면, 해당 파일을 읽음으로써 list의 출력을 얻을 수 있습니다. < 또는 >와 여는 소괄호 사이에는 공백이 올 수 없음에 유의하십시오. 공백이 있으면 해당 구조는 리다이렉션으로 해석됩니다.

프로세스 치환은 명명된 파이프(FIFO)나 열린 파일의 이름을 지정하는 /dev/fd 방식을 지원하는 시스템에서 사용할 수 있습니다.

사용 가능한 경우, 프로세스 치환은 파라미터 및 변수 확장, 명령어 치환, 그리고 산술 확장과 동시에 수행됩니다.
