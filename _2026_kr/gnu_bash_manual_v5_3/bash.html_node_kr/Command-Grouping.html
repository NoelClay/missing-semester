3.2.5.3 명령어 그룹화 ¶

Bash는 명령어 목록을 하나의 단위로 실행하기 위해 그룹화하는 두 가지 방법을 제공합니다. 명령어가 그룹화되면, 전체 명령어 목록에 대해 리다이렉션을 적용할 수 있습니다. 예를 들어, 목록 내의 모든 명령어의 출력을 단일 스트림으로 리다이렉트할 수 있습니다.

()
( list )

명령어 목록을 소괄호 사이에 두면 쉘은 서브쉘(명령어 실행 환경 참조)을 강제로 생성하며, list 내의 각 명령어는 해당 서브쉘 환경에서 실행됩니다. list가 서브쉘에서 실행되기 때문에, 서브쉘이 완료된 후에는 변수 할당이 유지되지 않습니다.

{} ¶
{ list; }

명령어 목록을 중괄호 사이에 두면 목록이 현재 쉘 환경에서 실행됩니다. 서브쉘은 생성되지 않습니다. list 뒤에는 세미콜론(또는 줄바꿈)이 반드시 필요합니다.

서브쉘 생성 여부 외에도, 역사적인 이유로 인해 이 두 구조 사이에는 미묘한 차이가 있습니다. 중괄호는 예약어이므로 blank(공백)나 다른 쉘 메타 문자에 의해 list와 구분되어야 합니다. 소괄호는 연산자이므로, list와 공백으로 구분되지 않더라도 쉘에 의해 별개의 토큰으로 인식됩니다.

두 구조의 종료 상태는 모두 list의 종료 상태입니다.
