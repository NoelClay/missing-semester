6.10 제한된 쉘 (The Restricted Shell) ¶

Bash가 rbash라는 이름으로 시작되거나, 호출 시 --restricted 또는 -r 옵션이 제공되면 쉘은 제한(restricted) 모드가 됩니다. 제한된 쉘은 표준 쉘보다 더 엄격하게 통제된 환경을 구축하기 위해 사용됩니다. 제한된 쉘은 다음과 같은 사항들이 허용되지 않거나 수행되지 않는다는 점을 제외하고 bash와 동일하게 동작합니다:

  • cd 빌트인을 사용한 디렉토리 변경.
  • SHELL, PATH, HISTFILE, ENV, 또는 BASH_ENV 변수값의 설정 또는 해제.
  • 슬래시(/)가 포함된 명령어 이름 지정.
  • . 빌트인 명령어의 인자로 슬래시가 포함된 파일 이름 지정.
  • 검색 경로를 지정하기 위해 . 빌트인 명령어의 -p 옵션 사용.
  • history 빌트인 명령어의 인자로 슬래시가 포함된 파일 이름 지정.
  • hash 빌트인 명령어의 -p 옵션 인자로 슬래시가 포함된 파일 이름 지정.
  • 시작 시 쉘 환경으로부터 함수 정의를 가져오기(import).
  • 시작 시 쉘 환경으로부터 SHELLOPTS 값을 파싱하기.
  • ‘>’, ‘>|’, ‘<>’, ‘>&’, ‘&>’, 그리고 ‘>>’ 리다이렉션 연산자를 사용한 출력 리다이렉션.
  • 현재 쉘을 다른 명령어로 대체하기 위해 exec 빌트인 사용.
  • enable 빌트인의 -f 및 -d 옵션을 사용하여 빌트인 명령어를 추가하거나 삭제하기.
  • 비활성화된 쉘 빌트인을 활성화하기 위해 enable 빌트인 명령어 사용.
  • command 빌트인의 -p 옵션 지정.
  • ‘set +r’ 또는 ‘shopt -u restricted_shell’ 명령으로 제한 모드 끄기.

이러한 제한 사항들은 모든 시작 파일들을 읽은 후에 적용됩니다.

쉘 스크립트로 판명된 명령어가 실행될 때(쉘 스크립트 참조), rbash는 스크립트 실행을 위해 생성된 쉘에서 모든 제한을 해제합니다.

제한된 쉘 모드는 유용한 제한 환경을 구성하기 위한 하나의 요소일 뿐입니다. 실제로는 오직 검증된 몇몇 명령어들만 실행할 수 있도록 PATH를 설정해야 하며(쉘 이스케이프 기능을 제공하는 명령어들은 특히 취약합니다), 로그인 후 현재 디렉토리를 $HOME 이외의 쓰기 권한이 없는 디렉토리로 변경하고, 제한된 쉘이 쉘 스크립트를 실행하지 못하도록 하며, 일부 명령어의 동작을 수정하게 만드는 환경 변수들(예: VISUAL 또는 PAGER)을 환경에서 정리하는 작업이 병행되어야 합니다.

현대적인 시스템들은 jails, zones, 또는 containers와 같이 제한된 환경을 구현하기 위한 더 안전한 방법들을 제공합니다.
