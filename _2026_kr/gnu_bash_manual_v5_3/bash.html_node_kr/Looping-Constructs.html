3.2.5.1 루프 구문 ¶

Bash는 다음과 같은 루프 구문을 지원합니다.

명령어 문법 설명에서 세미콜론(‘;’)이 나타나는 곳은 어디든 하나 이상의 줄바꿈으로 대체될 수 있습니다.

until ¶

until 명령어의 문법은 다음과 같습니다: 

until test-commands; do consequent-commands; done

test-commands의 종료 상태가 0이 아닌 동안 consequent-commands를 실행합니다. 반환 상태는 consequent-commands에서 마지막으로 실행된 명령어의 종료 상태이며, 실행된 명령어가 없는 경우 0입니다.

while ¶

while 명령어의 문법은 다음과 같습니다: 

while test-commands; do consequent-commands; done

test-commands의 종료 상태가 0인 동안 consequent-commands를 실행합니다. 반환 상태는 consequent-commands에서 마지막으로 실행된 명령어의 종료 상태이며, 실행된 명령어가 없는 경우 0입니다.

for ¶

for 명령어의 문법은 다음과 같습니다: 

for name [ [in words ...] ; ] do commands; done

words를 확장(쉘 확장 참조)한 후, 그 결과 목록의 각 단어에 대해 name에 현재 단어를 바인딩하여 commands를 한 번씩 실행합니다. ‘in words’가 없으면, 마치 ‘in "$@"’가 지정된 것처럼(특수 파라미터 참조) 설정된 각 위치 파라미터에 대해 commands를 한 번씩 실행합니다.

반환 상태는 마지막으로 실행된 명령어의 종료 상태입니다. words의 확장 결과에 항목이 없으면 명령어가 실행되지 않으며, 반환 상태는 0입니다.

for 명령어에는 C 언어와 유사한 또 다른 형식이 있습니다: 

for (( expr1 ; expr2 ; expr3 )) [;] do commands ; done

먼저, 아래에 설명된 규칙(쉘 산술 연산 참조)에 따라 산술식 expr1을 평가합니다. 그런 다음, 산술식 expr2가 0이 될 때까지 반복해서 평가합니다. expr2가 0이 아닌 값으로 평가될 때마다 commands를 실행하고 산술식 expr3을 평가합니다. 어떤 식이든 생략되면 1로 평가되는 것처럼 동작합니다. 반환 값은 실행된 commands 중 마지막 명령어의 종료 상태이며, 식 중 하나라도 유효하지 않으면 0이 아닌 값이 반환됩니다.

루프 실행을 제어하려면 break와 continue 빌트인 명령어(Bourne 쉘 빌트인 참조)를 사용하십시오.
