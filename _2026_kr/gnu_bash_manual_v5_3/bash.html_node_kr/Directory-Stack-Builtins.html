6.8.1 디렉토리 스택 빌트인 ¶

dirs ¶
dirs [-clpv] [+N | -N]

옵션이 없으면, 현재 기억된 디렉토리 목록을 표시합니다. 디렉토리는 pushd 명령어로 목록에 추가되고, popd 명령어로 목록에서 제거됩니다. 현재 디렉토리는 항상 스택의 첫 번째 디렉토리입니다.

제공되는 옵션들의 의미는 다음과 같습니다:

-c

모든 요소를 삭제하여 디렉토리 스택을 비웁니다.

-l

전체 경로명을 사용하여 목록을 생성합니다. 기본 목록 형식은 홈 디렉토리를 나타내기 위해 물결표(tilde)를 사용합니다.

-p

dirs가 한 줄에 하나의 항목씩 디렉토리 스택을 출력하도록 합니다.

-v

dirs가 한 줄에 하나의 항목씩 디렉토리 스택을 출력하며, 각 항목 앞에 스택 내 인덱스를 붙입니다.

+N

(옵션 없이 실행했을 때 출력되는 목록의 왼쪽부터 0부터 세어) N번째 디렉토리를 표시합니다.

-N

(옵션 없이 실행했을 때 출력되는 목록의 오른쪽부터 0부터 세어) N번째 디렉토리를 표시합니다.

popd ¶
popd [-n] [+N | -N]

디렉토리 스택에서 요소를 제거합니다. 요소 번호는 dirs로 나열된 첫 번째 디렉토리부터 0으로 시작합니다. 즉, popd는 popd +0과 동일합니다.

인자가 주어지지 않으면, popd는 스택의 최상단 디렉토리를 제거하고 새로운 최상단 디렉토리로 이동합니다.

제공되는 인자들의 의미는 다음과 같습니다:

-n

스택에서 디렉토리를 제거할 때 일반적인 디렉토리 변경을 억제하고 스택만 조작합니다.

+N

(dirs로 나열된 목록의 왼쪽부터 0부터 세어) N번째 디렉토리를 스택에서 제거합니다.

-N

(dirs로 나열된 목록의 오른쪽부터 0부터 세어) N번째 디렉토리를 스택에서 제거합니다.

디렉토리 스택의 최상단 요소가 수정되었고 -n 옵션이 제공되지 않았다면, popd는 cd 빌트인을 사용하여 스택 최상단에 있는 디렉토리로 이동합니다. 만약 cd가 실패하면 popd는 0이 아닌 값을 반환합니다.

그 외의 경우, 잘못된 옵션이 지정되었거나, 디렉토리 스택이 비어 있거나, N이 존재하지 않는 스택 항목을 지정하면 popd는 실패 상태를 반환합니다.

popd 명령어가 성공하면, Bash는 dirs를 실행하여 최종적인 디렉토리 스택 내용을 보여주며 반환 상태는 0입니다.

pushd ¶
pushd [-n] [+N | -N | dir]

디렉토리를 스택 최상단에 추가하거나 스택을 회전(rotate)시켜 새로운 최상단 디렉토리를 현재 작업 디렉토리로 만듭니다. 인자가 없으면 pushd는 스택 최상단의 두 요소를 서로 교체합니다.

제공되는 인자들의 의미는 다음과 같습니다:

-n

스택에 디렉토리를 추가하거나 회전시킬 때 일반적인 디렉토리 변경을 억제하고 스택만 조작합니다.

+N

(dirs로 나열된 목록의 왼쪽부터 0부터 세어) N번째 디렉토리가 최상단에 오도록 스택을 회전시킵니다.

-N

(dirs로 나열된 목록의 오른쪽부터 0부터 세어) N번째 디렉토리가 최상단에 오도록 스택을 회전시킵니다.

dir

dir을 스택 최상단에 추가합니다.

스택이 수정된 후, -n 옵션이 제공되지 않았다면 pushd는 cd 빌트인을 사용하여 스택 최상단에 있는 디렉토리로 이동합니다. 만약 cd가 실패하면 pushd는 0이 아닌 값을 반환합니다.

그 외의 경우, 인자가 주어지지 않았을 때 디렉토리 스택이 비어 있지 않다면 pushd는 0을 반환합니다. 스택을 회전시킬 때 스택이 비어 있지 않고 N이 유효한 스택 요소를 지정하면 pushd는 0을 반환합니다.

pushd 명령어가 성공하면, Bash는 dirs를 실행하여 최종적인 디렉토리 스택 내용을 보여줍니다.
