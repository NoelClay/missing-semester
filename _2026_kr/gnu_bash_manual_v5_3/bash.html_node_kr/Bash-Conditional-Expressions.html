6.4 Bash 조건식 ¶

조건식(Conditional expressions)은 [[ 복합 명령어(조건부 구문 참조)와 test 및 [ 빌트인 명령어(Bourne 쉘 빌트인 참조)에서 사용됩니다. test와 [ 명령어는 인자의 개수에 따라 동작을 결정합니다; 명령어별 추가 동작에 대해서는 해당 명령어들의 설명을 참조하십시오.

식은 단항(unary) 또는 이항(binary)일 수 있으며, 아래 나열된 기본 요소(primaries)들로 구성됩니다. 단항 식은 종종 파일이나 쉘 변수의 상태를 검사하는 데 사용됩니다. 이항 연산자는 문자열, 숫자, 그리고 파일 속성 비교를 위해 사용됩니다.

Bash는 식 내에서 사용되는 몇몇 파일 이름들을 특별하게 처리합니다. 만약 Bash가 실행 중인 운영체제가 이러한 특수 파일들을 제공한다면 Bash는 그것을 사용하고, 그렇지 않으면 아래 동작을 통해 내부적으로 에뮬레이트합니다: 만약 기본 요소의 file 인자가 /dev/fd/N 형식이면, Bash는 파일 서술자 N을 확인합니다. 만약 기본 요소의 file 인자가 /dev/stdin, /dev/stdout, 또는 /dev/stderr 중 하나라면, Bash는 각각 파일 서술자 0, 1, 또는 2를 확인합니다.

[[와 함께 사용될 때, ‘<’ 및 ‘>’ 연산자는 현재 로케일을 사용하여 사전순으로 정렬합니다. test 명령어는 ASCII 순서를 사용합니다.

별도로 언급하지 않는 한, 파일에 작용하는 기본 요소들은 심볼릭 링크를 따라가며 링크 자체가 아닌 링크의 대상을 대상으로 작용합니다.

-a file

file이 존재하면 참(true)입니다.

-b file

file이 존재하고 블록 특수 파일(block special file)이면 참입니다.

-c file

file이 존재하고 문자 특수 파일(character special file)이면 참입니다.

-d file

file이 존재하고 디렉토리이면 참입니다.

-e file

file이 존재하면 참입니다.

-f file

file이 존재하고 일반 파일(regular file)이면 참입니다.

-g file

file이 존재하고 set-group-id 비트가 설정되어 있으면 참입니다.

-h file

file이 존재하고 심볼릭 링크이면 참입니다.

-k file

file이 존재하고 "sticky" 비트가 설정되어 있으면 참입니다.

-p file

file이 존재하고 명명된 파이프(named pipe, FIFO)이면 참입니다.

-r file

file이 존재하고 읽기 가능하면 참입니다.

-s file

file이 존재하고 크기가 0보다 크면 참입니다.

-t fd

파일 서술자 fd가 열려 있고 터미널을 참조하고 있으면 참입니다.

-u file

file이 존재하고 set-user-id 비트가 설정되어 있으면 참입니다.

-w file

file이 존재하고 쓰기 가능하면 참입니다.

-x file

file이 존재하고 실행 가능하면 참입니다.

-G file

file이 존재하고 유효 그룹 ID(effective group id)에 의해 소유되고 있으면 참입니다.

-L file

file이 존재하고 심볼릭 링크이면 참입니다.

-N file

file이 존재하고 마지막으로 액세스된 이후에 수정되었다면 참입니다.

-O file

file이 존재하고 유효 사용자 ID(effective user id)에 의해 소유되고 있으면 참입니다.

-S file

file이 존재하고 소켓(socket)이면 참입니다.

file1 -ef file2

file1과 file2가 동일한 장치 및 아이노드(inode) 번호를 참조하고 있으면 참입니다.

file1 -nt file2

(수정 날짜 기준으로) file1이 file2보다 최신이거나, file1은 존재하는데 file2는 존재하지 않으면 참입니다.

file1 -ot file2

file1이 file2보다 오래되었거나, file2는 존재하는데 file1은 존재하지 않으면 참입니다.

-o optname

쉘 옵션 optname이 활성화되어 있으면 참입니다. 옵션 목록은 set 빌트인의 -o 옵션 설명 부분에 나와 있습니다(Set 빌트인 참조).

-v varname

쉘 변수 varname이 설정되어 있으면(값이 할당되어 있으면) 참입니다. 만약 varname이 ‘@’ 또는 ‘*’로 서브스크립트가 붙은 인덱스 배열 변수 이름인 경우, 배열에 설정된 요소가 하나라도 있으면 참을 반환합니다. 만약 varname이 ‘@’ 또는 ‘*’로 서브스크립트가 붙은 연관 배열 변수 이름인 경우, 해당 키를 가진 요소가 설정되어 있으면 참을 반환합니다.

-R varname

쉘 변수 varname이 설정되어 있고 네임레프(name reference) 속성을 가지고 있으면 참입니다.

-z string

string의 길이가 0이면 참입니다.

-n string
string

string의 길이가 0이 아니면 참입니다.

string1 == string2
string1 = string2

두 문자열이 동일하면 참입니다. [[ 명령어와 함께 사용될 때, 이는 위에서 설명한 패턴 매칭을 수행합니다(조건부 구문 참조). POSIX 준수를 위해서는 test 명령어와 함께 ‘=’를 사용해야 합니다.

string1 != string2

두 문자열이 동일하지 않으면 참입니다.

string1 < string2

string1이 string2보다 사전순으로 앞서면 참입니다.

string1 > string2

string1이 string2보다 사전순으로 뒤에 오면 참입니다.

arg1 OP arg2

OP는 ‘-eq’, ‘-ne’, ‘-lt’, ‘-le’, ‘-gt’, 또는 ‘-ge’ 중 하나입니다. 이러한 산술 이항 연산자들은 각각 arg1이 arg2와 같음, 같지 않음, 작음, 작거나 같음, 큼, 크거나 같음인 경우 참을 반환합니다. Arg1과 arg2는 양수 또는 음수 정수일 수 있습니다. [[ 명령어와 함께 사용될 때, arg1과 arg2는 산술식으로 평가됩니다(쉘 산술 연산 참조). [[ 명령어가 arg1과 arg2에 대해 수행하는 확장 결과가 잠재적으로 빈 문자열이 될 수 있으므로, 산술식 평가는 이를 0으로 평가되는 식으로 취급합니다.
