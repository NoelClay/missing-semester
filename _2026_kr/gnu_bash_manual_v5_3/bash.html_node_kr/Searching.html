8.2.5 히스토리에서 명령어 검색 ¶

Readline은 지정된 문자열을 포함하는 줄을 찾기 위해 명령어 히스토리(Bash 히스토리 기능 참조)를 검색하는 명령어를 제공합니다. 점진적(incremental) 검색과 비점진적(non-incremental) 검색의 두 가지 모드가 있습니다.

점진적 검색은 사용자가 검색 문자열 입력을 마치기 전부터 시작됩니다. 검색 문자열의 각 문자가 입력될 때마다 Readline은 지금까지 입력된 문자열과 일치하는 다음 히스토리 항목을 표시합니다. 점진적 검색은 원하는 히스토리 항목을 찾는 데 필요한 만큼의 문자만 입력하면 됩니다. Emacs 편집 모드를 사용할 때, 특정 문자열을 히스토리에서 역방향으로 검색하려면 C-r을 입력하십시오. C-s를 입력하면 히스토리에서 순방향으로 검색합니다. isearch-terminators 변수의 값에 포함된 문자들은 점진적 검색을 종료하는 데 사용됩니다. 해당 변수에 값이 할당되어 있지 않으면 ESC 및 C-j 문자가 점진적 검색을 종료시킵니다. C-g는 점진적 검색을 중단하고 원래의 줄을 복구합니다. 검색이 종료되면 검색 문자열을 포함하는 히스토리 항목이 현재 줄이 됩니다.

히스토리 목록에서 일치하는 다른 항목들을 찾으려면 상황에 맞게 C-r 또는 C-s를 입력하십시오. 이는 지금까지 입력된 검색 문자열과 일치하는 다음 항목을 히스토리에서 역방향 또는 순방향으로 검색합니다. Readline 명령어에 바인딩된 다른 키 시퀀스를 입력하면 검색을 종료하고 해당 명령어를 실행합니다. 예를 들어, RET는 검색을 종료하고 해당 줄을 수용하여 히스토리 목록의 명령어를 실행합니다. 이동 명령어는 검색을 종료하고 마지막으로 찾은 줄을 현재 줄로 만든 뒤 편집을 시작합니다.

Readline은 마지막 점진적 검색 문자열을 기억합니다. 새로운 검색 문자열을 정의하는 다른 문자 입력 없이 C-r을 연달아 두 번 입력하면, Readline은 기억된 검색 문자열을 사용합니다.

비점진적 검색은 일치하는 히스토리 항목 검색을 시작하기 전에 검색 문자열 전체를 먼저 읽습니다. 검색 문자열은 사용자가 직접 입력하거나 현재 줄의 내용 일부일 수 있습니다.
