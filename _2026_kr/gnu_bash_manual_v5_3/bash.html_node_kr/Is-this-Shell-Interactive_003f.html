6.3.2 이 쉘은 대화형인가? ¶

시작 스크립트 내에서 Bash가 대화형으로 실행 중인지 확인하려면 ‘-’ 특수 파라미터의 값을 테스트하십시오. 쉘이 대화형일 때 이 값은 i를 포함합니다. 예를 들어: 

case "$-" in
*i*)	echo 이 쉘은 대화형입니다 ;;
*)	echo 이 쉘은 대화형이 아닙니다 ;;
esac

대안적으로, 시작 스크립트에서 PS1 변수를 조사할 수도 있습니다; 이 변수는 비대화형 쉘에서는 해제(unset)되어 있고, 대화형 쉘에서는 설정되어 있습니다. 따라서: 

if [ -z "$PS1" ]; then
        echo 이 쉘은 대화형이 아닙니다
else
        echo 이 쉘은 대화형입니다
fi
