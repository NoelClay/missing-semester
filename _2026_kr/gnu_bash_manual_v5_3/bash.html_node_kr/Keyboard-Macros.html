8.4.7 키보드 매크로 ¶

start-kbd-macro (C-x () ¶

현재 키보드 매크로에 입력된 문자들을 저장하기 시작합니다.

end-kbd-macro (C-x )) ¶

현재 키보드 매크로에 입력된 문자들을 저장하는 것을 중단하고 정의를 저장합니다.

call-last-kbd-macro (C-x e) ¶

마지막으로 정의된 키보드 매크로를 다시 실행합니다. 매크로에 저장된 문자들이 키보드에서 직접 입력된 것처럼 나타나게 합니다.

print-last-kbd-macro () ¶

마지막으로 정의된 키보드 매크로를 inputrc 파일에 적합한 형식으로 출력합니다.
