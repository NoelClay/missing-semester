10.7 작업 제어 (Operation Controls) ¶

configure는 동작 방식을 제어하기 위해 다음 옵션들을 인식합니다.

--cache-file=file

테스트 결과를 ./config.cache 대신 file에 사용하고 저장합니다. configure를 디버깅할 때 캐싱을 비활성화하려면 file을 /dev/null로 설정하십시오.

--help

configure 옵션들에 대한 요약을 출력하고 종료합니다.

--quiet
--silent
-q

어떤 확인(checks)들이 수행되고 있는지 알려주는 메시지들을 출력하지 않습니다.

--srcdir=dir

Bash 소스 코드를 dir 디렉토리에서 찾습니다. 보통 configure는 해당 디렉토리를 자동으로 결정할 수 있습니다.

--version

configure 스크립트를 생성하는 데 사용된 Autoconf의 버전을 출력하고 종료합니다.

configure는 널리 사용되지 않는 몇 가지 다른 표준 옵션들도 받아들입니다. ‘configure --help’는 전체 목록을 출력합니다.
