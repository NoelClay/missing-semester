3.7.5 종료 상태 (Exit Status) ¶

실행된 명령어의 종료 상태(exit status)는 waitpid 시스템 콜 또는 그와 동등한 함수가 반환하는 값입니다. 종료 상태는 0에서 255 사이의 값을 갖지만, 아래 설명된 대로 쉘은 125 이상의 값들을 특별한 의미로 사용하기도 합니다. 쉘 빌트인 및 복합 명령어의 종료 상태 또한 이 범위로 제한됩니다. 특정 상황에서 쉘은 특정한 실패 모드를 나타내기 위해 특별한 값들을 사용합니다.

쉘의 관점에서, 종료 상태 0으로 종료된 명령어는 성공한 것입니다. 따라서 종료 상태 0은 성공을 의미하며, 0이 아닌 종료 상태는 실패를 의미합니다. 겉보기에 직관에 반하는 것처럼 보이는 이러한 체계가 사용되는 이유는, 성공을 나타내는 확실한 방법 하나와 다양한 실패 모드를 나타내는 여러 가지 방법들을 제공하기 위해서입니다.

명령어가 번호가 N인 치명적인 시그널에 의해 종료된 경우, Bash는 128+N을 종료 상태로 사용합니다.

명령어를 찾을 수 없는 경우, 이를 실행하기 위해 생성된 자식 프로세스는 상태 127을 반환합니다. 명령어를 찾았으나 실행 가능하지 않은 경우, 반환 상태는 126입니다.

확장 또는 리다이렉션 과정에서의 에러로 인해 명령어가 실패한 경우, 종료 상태는 0보다 큽니다.

종료 상태는 Bash의 조건부 명령어(조건부 구문 참조) 및 일부 목록 구조(명령어 목록 참조)에서 사용됩니다.

모든 Bash 빌트인은 성공 시 0을 반환하고 실패 시 0이 아닌 상태를 반환하므로, 조건부 및 목록 구조에서 사용될 수 있습니다. 모든 빌트인은 잘못된 사용법(일반적으로 잘못된 옵션이나 인자 누락)을 나타내기 위해 종료 상태 2를 반환합니다.

마지막 명령어의 종료 상태는 특수 파라미터 $?에서 확인할 수 있습니다(특수 파라미터 참조).

문법 에러가 발생하여 0이 아닌 값으로 종료되는 경우를 제외하고, Bash 자체는 마지막으로 실행된 명령어의 종료 상태를 반환합니다. 또한 exit 빌트인 명령어(Bourne 쉘 빌트인 참조)를 확인하십시오.
