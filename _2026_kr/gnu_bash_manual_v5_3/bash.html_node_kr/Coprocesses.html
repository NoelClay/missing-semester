3.2.6 코프로세스 ¶

코프로세스(coprocess)는 예약어 coproc가 앞에 붙은 쉘 명령어입니다. 코프로세스는 마치 명령어가 ‘&’ 제어 연산자로 종료된 것처럼 서브쉘에서 비동기적으로 실행되며, 실행 중인 쉘과 코프로세스 사이에 양방향 파이프가 생성됩니다.

코프로세스의 문법은 다음과 같습니다: 

coproc [NAME] command [redirections]

이는 NAME이라는 이름의 코프로세스를 생성합니다. command는 단순 명령어(단순 명령어 참조) 또는 복합 명령어(복합 명령어 참조)일 수 있습니다. NAME은 쉘 변수 이름입니다. NAME이 제공되지 않으면 기본 이름은 COPROC입니다.

코프로세스에 권장되는 사용 형식은 다음과 같습니다: 

coproc NAME { command; }

이 형식이 선호되는 이유는 단순 명령어를 사용할 경우 코프로세스 이름이 항상 COPROC로 지정되기 때문이며, 또한 다른 복합 명령어들보다 사용하기 간단하고 완전하기 때문입니다.

코프로세스의 다른 형식들은 다음과 같습니다: 

coproc NAME compound-command
coproc compound-command
coproc simple-command

command가 복합 명령어인 경우 NAME은 선택 사항입니다. coproc 뒤에 오는 단어가 변수 이름으로 해석될지 여부는 해당 단어가 복합 명령어를 시작하는 예약어인지에 따라 결정됩니다. 예약어가 아니면 NAME으로 해석됩니다. command가 단순 명령어인 경우 NAME은 허용되지 않습니다. 이는 NAME과 단순 명령어의 첫 번째 단어 사이의 혼동을 피하기 위함입니다.

코프로세스가 실행될 때, 쉘은 실행 중인 쉘의 컨텍스트에 NAME이라는 이름의 배열 변수(배열 참조)를 생성합니다. command의 표준 출력은 실행 중인 쉘의 파일 서술자와 파이프로 연결되며, 그 파일 서술자는 NAME[0]에 할당됩니다. command의 표준 입력은 실행 중인 쉘의 파일 서술자와 파이프로 연결되며, 그 파일 서술자는 NAME[1]에 할당됩니다. 이 파이프는 명령어에 지정된 그 어떤 리다이렉션보다도 먼저 생성됩니다(리다이렉션 참조). 이 파일 서술자들은 표준 단어 확장을 사용하여 쉘 명령어의 인자나 리다이렉션으로 활용될 수 있습니다. 명령어 치환 및 프로세스 치환을 실행하기 위해 생성된 파일 서술자들을 제외하고, 이 파일 서술자들은 서브쉘에서는 사용할 수 없습니다.

코프로세스를 실행하기 위해 생성된 쉘의 프로세스 ID는 NAME_PID 변수의 값으로 확인할 수 있습니다. wait 빌트인 명령어를 사용하여 코프로세스가 종료될 때까지 기다릴 수 있습니다.

코프로세스는 비동기 명령어로 생성되므로, coproc 명령어 자체는 항상 성공을 반환합니다. 코프로세스의 반환 상태는 command의 종료 상태입니다.
