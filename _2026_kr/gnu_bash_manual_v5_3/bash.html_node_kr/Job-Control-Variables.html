7.3 작업 제어 변수 ¶

auto_resume ¶

이 변수는 쉘이 사용자와 작업 제어 시스템 사이에서 어떻게 상호작용할지를 제어합니다. 이 변수가 존재하면, 리다이렉션 없이 단일 단어로만 구성된 단순 명령어는 기존 작업의 재개(resumption) 후보로 간주됩니다. 모호함은 허용되지 않습니다; 해당 단어로 시작하거나 단어를 포함하는 작업이 둘 이상인 경우 가장 최근에 접근된 작업을 선택합니다. 이 컨텍스트에서 중단된 작업의 이름은 jobs 명령어로 표시되는, 작업을 시작할 때 사용된 명령줄입니다. 만약 이 변수의 값이 ‘exact’로 설정되어 있다면, 입력된 단어가 중단된 작업의 이름과 정확히 일치해야 합니다; ‘substring’으로 설정되어 있다면, 단어가 중단된 작업 이름의 부분 문자열과 일치하면 됩니다. ‘substring’ 값은 ‘%?string’ 작업 ID와 유사한 기능을 제공합니다(작업 제어 기초 참조). 그 외의 값(예: ‘prefix’)으로 설정된 경우, 단어는 중단된 작업 이름의 접두사여야 하며, 이는 ‘%string’ 작업 ID와 유사한 기능을 제공합니다.
