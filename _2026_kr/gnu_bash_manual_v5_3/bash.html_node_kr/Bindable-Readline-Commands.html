8.4 바인딩 가능한 Readline 명령어 ¶

이 섹션은 키 시퀀스에 바인딩될 수 있는 Readline 명령어들에 대해 설명합니다. bind -P 명령어를 실행하여 현재의 키 바인딩 목록을 확인하거나, inputrc 파일에 적합한 더 간결한 형식인 bind -p를 사용할 수 있습니다. (Bash 빌트인 명령어 참조.) 키 시퀀스가 할당되지 않은 명령어 이름들은 기본적으로 바인딩되지 않은(unbound) 상태입니다.

이하의 설명에서, 포인트(point)는 현재 커서 위치를 참조하고, 마크(mark)는 set-mark 명령어에 의해 저장된 커서 위치를 참조합니다. 포인트와 마크 사이의 텍스트를 리전(region)이라고 부릅니다. Readline에는 활성 리전(active region)이라는 개념이 있습니다: 리전이 활성 상태일 때, Readline은 active-region-start-color 변수 값을 사용하여 리전을 다시 그릴 때 강조 표시합니다. enable-active-region 변수가 이 기능을 켜고 끕니다. 리전을 활성 상태로 설정하는 여러 명령어들이 있으며, 이는 아래에 언급되어 있습니다.

  • 이동 명령어
  • 히스토리 조작 명령어
  • 텍스트 변경 명령어
  • 삭제 및 붙여넣기(Yanking)
  • 숫자 인자 지정하기
  • 자동 완성 명령어
  • 키보드 매크로
  • 기타 명령어들
