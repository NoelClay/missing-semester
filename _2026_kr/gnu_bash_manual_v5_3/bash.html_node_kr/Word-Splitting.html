3.5.7 단어 분할 ¶

쉘은 큰따옴표 내에서 발생하지 않은 파라미터 확장, 명령어 치환, 그리고 산술 확장의 결과물에 대해 단어 분할(word splitting)을 수행하기 위해 스캔합니다. 확장되지 않은 단어들은 분할되지 않습니다.

쉘은 $IFS의 각 문자를 구분자(delimiter)로 취급하며, 이 문자들을 필드 종료자로 사용하여 다른 확장들의 결과를 여러 필드로 분할합니다.

IFS 공백(IFS whitespace) 문자란 위에서 정의된 공백 문자(용어 정의 참조) 중 IFS의 값에 포함된 문자를 의미합니다. 스페이스, 탭, 줄바꿈은 로케일의 space 범주에 포함되지 않더라도 항상 IFS 공백으로 간주됩니다.

만약 IFS가 설정되어 있지 않으면, 단어 분할은 마치 그 값이 <space><tab><newline>인 것처럼 동작하며, 이 문자들을 IFS 공백으로 취급합니다. 만약 IFS의 값이 null(빈 값)이면 단어 분할은 일어나지 않지만, 암시적인 null 인자(아래 참조)는 여전히 제거됩니다.

단어 분할은 이전 확장 결과의 시작과 끝에서 IFS 공백 문자 시퀀스를 제거하는 것으로 시작하며, 그 후에 남은 단어들을 분할합니다.

만약 IFS의 값이 오직 IFS 공백으로만 구성되어 있다면, 임의의 IFS 공백 문자 시퀀스가 필드를 구분합니다. 따라서 필드는 인용되지 않은 IFS 공백이 아닌 문자들로 구성되며, null 필드는 오직 인용을 통해서만 생길 수 있습니다.

만약 IFS에 공백이 아닌 문자가 포함되어 있다면, IFS 공백이 아닌 IFS 내의 모든 문자와 그에 인접한 모든 IFS 공백 문자들이 필드를 구분합니다. 이는 인접한 'IFS 공백이 아닌 구분자'들이 null 필드를 생성함을 의미합니다. IFS 공백 문자들의 시퀀스 또한 필드를 구분합니다.

명시적인 null 인자("" 또는 '')는 보존되어 명령어에 빈 문자열로 전달됩니다. 값이 없는 파라미터의 확장으로 인해 발생하는 인용되지 않은 암시적인 null 인자들은 제거됩니다. 값이 없는 파라미터를 큰따옴표 내에서 확장하면 null 필드가 생성되며, 이는 보존되어 명령어에 빈 문자열로 전달됩니다.

인용된 null 인자가 확장의 결과가 null이 아닌 단어의 일부로 나타나는 경우, 단어 분할 시 null 인자 부분은 제거되고 null이 아닌 확장 결과만 남습니다. 즉, 단어 -d''는 단어 분할과 null 인자 제거 후에 -d가 됩니다.
