3.5.8.1 패턴 매칭 ¶

아래에 설명된 특수 패턴 문자들을 제외하고, 패턴에 나타나는 모든 문자는 그 자신과 매치됩니다. NUL 문자는 패턴에 나타날 수 없습니다. 백슬래시는 바로 뒤에 오는 문자를 이스케이프하며, 매칭 시 이스케이프용 백슬래시는 버려집니다. 특수 패턴 문자들을 리터럴로 매치하려면 반드시 인용되어야 합니다.

특수 패턴 문자들은 다음과 같은 의미를 갖습니다:

*

null(빈) 문자열을 포함하여 모든 문자열과 매치됩니다. globstar 쉘 옵션이 활성화되어 있고 ‘*’가 파일 이름 확장 컨텍스트에서 사용될 때, 단일 패턴으로 사용된 두 개의 인접한 ‘*’은 모든 파일과 0개 이상의 디렉토리 및 하위 디렉토리에 매치됩니다. 뒤에 ‘/’가 오면, 두 개의 인접한 ‘*’은 오직 디렉토리와 하위 디렉토리에만 매치됩니다.

?

임의의 단일 문자와 매치됩니다.

[…]

대괄호 사이에 포함된 문자들 중 하나와 매치됩니다. 이를 대괄호 표현식(bracket expression)이라고 하며 단일 문자와 매치됩니다. 하이픈으로 구분된 한 쌍의 문자는 범위 표현식(range expression)을 나타냅니다. 현재 로케일의 정렬 순서(collating sequence)와 문자 집합을 기준으로 두 문자 사이에 있는 모든 문자(양 끝값 포함)와 매치됩니다. 만약 ‘[’ 뒤의 첫 번째 문자가 ‘!’ 또는 ‘^’이면 해당 범위에 포함되지 않는 모든 문자와 매치됩니다. ‘-’ 자체를 매치하려면 집합의 첫 번째 또는 마지막 문자로 포함시키십시오. ‘]’ 자체를 매치하려면 집합의 첫 번째 문자로 포함시키십시오.

범위 표현식에서의 문자 정렬 순서와 범위에 포함되는 문자들은 현재 로케일과 LC_COLLATE 및 LC_ALL 쉘 변수의 설정값에 의해 결정됩니다.

예를 들어, 기본 C 로케일에서 ‘[a-dx-z]’는 ‘[abcdxyz]’와 동일합니다. 많은 로케일들이 사전식 순서로 문자를 정렬하며, 이러한 로케일들에서 ‘[a-dx-z]’는 보통 ‘[abcdxyz]’와 동일하지 않습니다. 예를 들어 ‘[aBbCcDdxYyZz]’와 동일할 수도 있습니다. 대괄호 표현식에서 전통적인 범위 해석을 사용하려면, LC_COLLATE 또는 LC_ALL 환경 변수를 ‘C’로 설정하여 C 로케일 사용을 강제하거나, globasciiranges 쉘 옵션을 활성화하십시오.

대괄호 표현식 내에서 문자 클래스(character classes)를 [:class:] 문법을 사용하여 지정할 수 있습니다. 여기서 class는 POSIX 표준에 정의된 다음 클래스들 중 하나입니다: 

alnum   alpha   ascii   blank   cntrl   digit   graph   lower
print   punct   space   upper   word    xdigit

문자 클래스는 해당 클래스에 속하는 모든 문자와 매치됩니다. word 문자 클래스는 알파벳, 숫자, 그리고 ‘_’ 문자와 매치됩니다.

예를 들어, 다음 패턴은 현재 로케일의 space 문자 클래스에 속하는 임의의 문자, 그 뒤에 대문자 알파벳이나 ‘!’, 그 뒤에 점(.), 그리고 마지막으로 소문자 알파벳이나 하이픈 하나와 매치됩니다. 

[[:space:]][[:upper:]!].[-[:lower:]]

대괄호 표현식 내에서 동등 클래스(equivalence class)를 [=c=] 문법을 사용하여 지정할 수 있습니다. 이는 문자 c와 동일한 정렬 가중치(현재 로케일에 정의된 기준)를 가진 모든 문자와 매치됩니다.

대괄호 표현식 내에서 [.symbol.] 문법은 정렬 기호(collating symbol) symbol과 매치됩니다.

만약 shopt 빌트인을 통해 extglob 쉘 옵션이 활성화되어 있다면, 쉘은 여러 확장 패턴 매칭 연산자들을 인식합니다. 아래 설명에서 pattern-list는 ‘|’로 구분된 하나 이상의 패턴 목록입니다. 파일 이름을 매칭할 때, 위에서 설명한 대로 dotglob 쉘 옵션이 검사 대상 파일 이름 집합을 결정합니다. 복합 패턴(composite patterns)은 다음 서브 패턴들 중 하나 이상을 사용하여 형성될 수 있습니다:

?(pattern-list)

제공된 패턴들이 0번 또는 1번 나타나는 경우와 매치됩니다.

*(pattern-list)

제공된 패턴들이 0번 이상 나타나는 경우와 매치됩니다.

+(pattern-list)

제공된 패턴들이 1번 이상 나타나는 경우와 매치됩니다.

@(pattern-list)

제공된 패턴들 중 정확히 하나와 매치됩니다.

!(pattern-list)

제공된 패턴들 중 하나와 매치되는 것을 제외한 모든 것과 매치됩니다.

소괄호는 보통 구문론적 의미를 갖는 연산자로 취급되기 때문에, extglob 옵션은 파서의 동작을 변경합니다. 확장 매칭 패턴이 올바르게 파싱되도록 하려면, 쉘 함수나 명령어 치환을 포함하여 해당 패턴을 포함하는 구조를 파싱하기 전에 extglob이 활성화되어 있는지 확인하십시오.

파일 이름을 매칭할 때, dotglob 쉘 옵션이 검사 대상 파일 이름 집합을 결정합니다: dotglob이 활성화되어 있으면 파일 이름 집합에 ‘.’으로 시작하는 모든 파일이 포함되지만, . 및 .. 파일 이름은 반드시 점으로 시작하는 패턴이나 서브 패턴에 의해 매치되어야 합니다. 비활성화되어 있으면 패턴이나 서브 패턴이 ‘.’으로 시작하지 않는 한 ‘.’으로 시작하는 파일 이름은 집합에 포함되지 않습니다. 만약 globskipdots 쉘 옵션이 활성화되어 있으면, . 및 .. 파일 이름은 집합에 절대 나타나지 않습니다. 위에서 언급했듯이, ‘.’ 문자는 오직 파일 이름을 매칭할 때만 특별한 의미를 갖습니다.

긴 문자열에 대한 복잡한 확장 패턴 매칭은 속도가 느릴 수 있으며, 특히 패턴에 선택(alternation)이 포함되어 있고 문자열에 여러 매칭 지점이 있는 경우 더욱 그렇습니다. 짧은 문자열에 대해 별도로 매칭을 수행하거나, 하나의 긴 문자열 대신 문자열 배열을 사용하는 것이 더 빠를 수 있습니다.
