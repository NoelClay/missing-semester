10.4 설치 이름 (Installation Names) ¶

기본적으로 ‘make install’은 /usr/local/bin, /usr/local/man 등에 설치합니다; 즉, 설치 접두사(installation prefix)의 기본값은 /usr/local입니다. configure에 --prefix=PATH 옵션을 주거나, ‘make install’을 실행할 때 prefix ‘make’ 변수 값을 지정함으로써(예: ‘make install prefix=PATH’) /usr/local 이외의 설치 접두사를 지정할 수 있습니다. prefix 변수는 exec_prefix 및 Bash 설치 시 사용되는 다른 변수들의 기본값을 제공합니다.

아키텍처 의존적인 파일들과 아키텍처 독립적인 파일들에 대해 별도의 설치 접두사를 지정할 수 있습니다. configure에 --exec-prefix=PATH 옵션을 주면, ‘make install’은 프로그램과 라이브러리를 설치하기 위한 접두사로 PATH를 사용할 것입니다. 문서 및 다른 데이터 파일들은 여전히 일반 접두사를 사용합니다.

단 한 번의 실행에 대해서만 설치 위치를 변경하고 싶다면, 이 변수들을 make의 인자로 지정할 수 있습니다: ‘make install exec_prefix=/’는 bash와 bashbug를 기본 위치인 /usr/local/bin 대신 /bin에 설치할 것입니다.

시스템의 어떤 것도 변경하지 않고 Bash가 어떤 파일들을 어디에 설치할지 확인하고 싶다면, DESTDIR 변수를 make의 인자로 지정하십시오. 그 값은 샘플 설치 트리의 루트로 사용하고자 하는 절대 디렉토리 경로여야 합니다. 예를 들어, 

mkdir /fs1/bash-install
make install DESTDIR=/fs1/bash-install

위 명령어는 bash를 /fs1/bash-install/usr/local/bin/bash에 설치하고, 문서를 /fs1/bash-install/usr/local/share 내의 디렉토리들에 설치하며, 예시 로드 가능한 빌트인들을 /fs1/bash-install/usr/local/lib/bash에 설치하는 등의 작업을 수행할 것입니다. DESTDIR 값 아래의 디렉토리 경로를 변경하기 위해 평소와 같이 exec_prefix 및 prefix 변수들을 사용할 수 있습니다.

GNU Makefile 표준은 이러한 변수들과 그 효과에 대해 더 완전한 설명을 제공합니다.
