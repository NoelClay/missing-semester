3.7.4 환경 (Environment) ¶

프로그램이 호출될 때 해당 프로그램에는 환경(environment)이라고 불리는 문자열 배열이 제공됩니다. 이는 이름=값 형식의 이름-값 쌍의 목록입니다.

Bash는 환경을 조작하는 여러 가지 방법을 제공합니다. 호출 시 쉘은 자신의 환경을 스캔하고 발견된 각 이름에 대해 파라미터를 생성하며, 자식 프로세스로 export(내보내기)되도록 자동으로 표시합니다. 실행되는 명령어들은 이 환경을 상속받습니다. export, ‘declare -x’, 그리고 unset 명령어는 파라미터와 함수를 추가하거나 삭제함으로써 환경을 수정합니다. 환경 내의 파라미터 값이 수정되면, 새로운 값이 기존 값을 대체하여 자동으로 환경의 일부가 됩니다. 모든 실행되는 명령어가 상속받는 환경은 쉘의 초기 환경(쉘 내부에서 수정되었을 수 있음)에서 unset 및 ‘export -n’ 명령어로 제거된 쌍들을 빼고, export 및 ‘declare -x’ 명령어로 추가된 것들을 더하여 구성됩니다.

쉘 파라미터에 설명된 파라미터 할당문이 단순 명령어 앞에 나타나면, 해당 변수 할당은 그 명령어가 실행되는 동안만 해당 명령어 환경의 일부가 됩니다. 이러한 할당문은 오직 해당 명령어가 보게 되는 환경에만 영향을 미칩니다. 만약 이러한 할당문이 쉘 함수 호출 앞에 온다면, 변수들은 해당 함수의 지역 변수가 되며 해당 함수의 자식 프로세스들에게 내보내집니다.

만약 -k 옵션이 설정되어 있다면(Set 빌트인 참조), 명령어 이름 앞에 오는 것뿐만 아니라 모든 파라미터 할당이 명령어의 환경에 배치됩니다.

Bash가 외부 명령어를 호출할 때, 변수 ‘$_’은 해당 명령어의 전체 경로명으로 설정되어 해당 명령어의 환경으로 전달됩니다.
