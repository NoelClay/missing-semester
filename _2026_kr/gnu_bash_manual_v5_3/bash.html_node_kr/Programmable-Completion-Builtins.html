8.7 프로그래밍 가능한 자동 완성 빌트인 ¶

프로그래밍 가능한 자동 완성 시설을 조작하기 위해 세 가지 빌트인 명령어를 사용할 수 있습니다: 하나는 특정 명령어의 인자가 어떻게 자동 완성되어야 하는지 지정하는 것이고, 나머지 둘은 자동 완성이 진행되는 도중에 이를 수정하는 것입니다.

compgen ¶
compgen [-V varname] [option] [word]

option들에 따라 word에 대해 가능한 자동 완성 일치 항목들을 생성합니다. option은 -p, -r, -D, -E, 그리고 -I를 제외하고 complete 빌트인에서 허용되는 모든 옵션이 가능하며, 일치 항목들을 표준 출력으로 씁니다.

만약 -V 옵션이 제공되면, compgen은 생성된 자동 완성 후보들을 표준 출력으로 내보내는 대신 인덱스 배열 변수 varname에 저장합니다.

-F 또는 -C 옵션을 사용할 때, 프로그래밍 가능한 자동 완성 시설에 의해 설정된 다양한 쉘 변수들은 사용 가능하긴 하지만 유용한 값을 가지지는 않습니다.

일치 항목들은 프로그래밍 가능한 자동 완성 코드가 동일한 플래그를 가진 자동 완성 사양(compspec)으로부터 직접 생성한 것과 동일한 방식으로 생성됩니다. 만약 word가 지정되면, word와 일치하는 자동 완성 후보들만 표시되거나 저장됩니다.

반환 값은 잘못된 옵션이 제공되거나 일치 항목이 생성되지 않은 경우를 제외하고 참(true)입니다.

complete ¶
complete [-abcdefgjksuv] [-o comp-option] [-DEI] [-A action]
[-G globpat] [-W wordlist] [-F function] [-C command]
[-X filterpat] [-P prefix] [-S suffix] name [name ...]
complete -pr [-DEI] [name ...]

각 name에 대한 인자들이 어떻게 자동 완성되어야 하는지 지정합니다.

만약 -p 옵션이 제공되거나 옵션 또는 name이 전혀 제공되지 않으면, 기존의 자동 완성 사양들을 입력으로 재사용할 수 있는 형식으로 출력합니다. -r 옵션은 각 name에 대한 자동 완성 사양을 제거하거나, name이 주어지지 않은 경우 모든 자동 완성 사양을 제거합니다.

실제 스크립팅에서의 편의를 위해 -D 옵션은 다른 옵션들과 액션들이 “기본(default)” 명령어 자동 완성에 적용되어야 함을 나타냅니다; 즉, 이전에 자동 완성이 정의되지 않은 명령어에 대해 자동 완성이 시도될 때 사용됩니다. -E 옵션은 “빈(empty)” 명령어 자동 완성, 즉 빈 줄에서 자동 완성이 시도될 때 적용됨을 나타냅니다. -I 옵션은 줄의 첫 번째 할당문이 아닌 단어, 또는 ‘;’ 나 ‘|’와 같은 명령어 구분자 뒤의 첫 단어에 대한 자동 완성에 적용됨을 나타내며, 이는 대개 명령어 이름 완성입니다. 만약 여러 옵션이 제공되면 -D 옵션이 -E보다 우선하고, 둘 다 -I보다 우선합니다. 만약 -D, -E, 또는 -I 중 하나라도 제공되면 다른 모든 name 인자들은 무시됩니다; 이러한 자동 완성은 해당 옵션으로 지정된 케이스에만 적용됩니다.

단어 자동 완성이 시도될 때 이러한 자동 완성 사양들을 적용하는 과정은 위에서 설명되었습니다(프로그래밍 가능한 자동 완성 참조).

기타 지정된 옵션들은 다음과 같은 의미를 갖습니다. -G, -W, 그리고 -X 옵션(그리고 필요한 경우 -P 및 -S 옵션)의 인자들은 complete 빌트인이 호출되기 전에 확장되는 것을 방지하기 위해 반드시 인용 처리되어야 합니다.

-o comp-option

comp-option은 단순한 자동 완성 후보 생성을 넘어 compspec의 여러 동작 측면을 제어합니다. comp-option은 다음 중 하나일 수 있습니다:

bashdefault

compspec이 일치 항목을 생성하지 못한 경우 Bash의 나머지 기본 자동 완성을 수행합니다.

default

compspec이 일치 항목을 생성하지 못한 경우 Readline의 기본 파일 이름 완성을 사용합니다.

dirnames

compspec이 일치 항목을 생성하지 못한 경우 디렉토리 이름 완성을 수행합니다.

filenames

Readline에 compspec이 파일 이름을 생성함을 알려서, Readline이 파일 이름 전용 처리(디렉토리 이름 뒤에 슬래시 추가, 특수 문자 인용 처리, 또는 끝부분의 공백 억제 등)를 수행할 수 있게 합니다. 이 옵션은 -F로 지정된 쉘 함수와 함께 사용하도록 고안되었습니다.

fullquote

Readline이 파일 이름이 아니더라도 모든 완성된 단어들을 인용 처리하도록 합니다.

noquote

완성된 단어들이 파일 이름이더라도 Readline이 이를 인용 처리하지 않도록 합니다(파일 이름 인용은 기본 동작입니다).

nosort

Readline이 가능한 자동 완성 후보 목록을 알파벳 순서로 정렬하지 않도록 합니다.

nospace

줄의 끝에서 완성된 단어들 뒤에 공백을 추가하지 않도록 Readline에 지시합니다(공백 추가는 기본 동작입니다).

plusdirs

compspec에 정의된 모든 일치 항목을 생성한 후, 추가로 디렉토리 이름 완성을 시도하여 발견된 모든 일치 항목을 다른 액션들의 결과에 추가합니다.

-A action

action은 가능한 자동 완성 후보 목록을 생성하기 위해 다음 중 하나일 수 있습니다:

alias

별칭(Alias) 이름들. -a로도 지정할 수 있습니다.

arrayvar

배열 변수 이름들.

binding

Readline 키 바인딩 이름들(바인딩 가능한 Readline 명령어 참조).

builtin

쉘 빌트인 명령어의 이름들. -b로도 지정할 수 있습니다.

command

명령어 이름들. -c로도 지정할 수 있습니다.

directory

디렉토리 이름들. -d로도 지정할 수 있습니다.

disabled

비활성화된 쉘 빌트인의 이름들.

enabled

활성화된 쉘 빌트인의 이름들.

export

내보내기(export)된 쉘 변수의 이름들. -e로도 지정할 수 있습니다.

file

파일 및 디렉토리 이름들. Readline의 파일 이름 완성 기능과 유사합니다. -f로도 지정할 수 있습니다.

function

쉘 함수의 이름들.

group

그룹 이름들. -g로도 지정할 수 있습니다.

helptopic

help 빌트인에서 허용되는 도움말 주제들(Bash 빌트인 명령어 참조).

hostname

HOSTFILE 쉘 변수로 지정된 파일로부터 가져온 호스트 이름들(Bash 변수 참조).

job

작업 제어가 활성 상태인 경우 작업(Job) 이름들. -j로도 지정할 수 있습니다.

keyword

쉘 예약어들. -k로도 지정할 수 있습니다.

running

작업 제어가 활성 상태인 경우 실행 중인 작업의 이름들.

service

서비스 이름들. -s로도 지정할 수 있습니다.

setopt

set 빌트인의 -o 옵션에 대한 유효한 인자들(Set 빌트인 참조).

shopt

shopt 빌트인에서 허용되는 쉘 옵션 이름들(Bash 빌트인 명령어 참조).

signal

시그널 이름들.

stopped

작업 제어가 활성 상태인 경우 중단된 작업의 이름들.

user

사용자 이름들. -u로도 지정할 수 있습니다.

variable

모든 쉘 변수의 이름들. -v로도 지정할 수 있습니다.

-C command

command는 서브쉘 환경에서 실행되며, 그 출력 결과가 가능한 자동 완성 후보로 사용됩니다. 인자들은 -F 옵션과 동일한 방식으로 전달됩니다.

-F function

쉘 함수 function은 현재 쉘 환경에서 실행됩니다. 함수 실행 시 첫 번째 인자($1)는 인자가 완성 중인 명령어의 이름이고, 두 번째 인자($2)는 완성 중인 단어이며, 세 번째 인자($3)는 위에서 설명한 대로 완성 중인 단어 바로 앞의 단어입니다(프로그래밍 가능한 자동 완성 참조). function이 완료되면, 프로그래밍 가능한 자동 완성 시설은 COMPREPLY 배열 변수 값으로부터 가능한 자동 완성 후보들을 가져옵니다.

-G globpat

파일명 확장 패턴 globpat을 확장하여 가능한 자동 완성 후보들을 생성합니다.

-P prefix

다른 모든 옵션들이 적용된 후, 가능한 각 자동 완성 후보의 시작 부분에 prefix를 추가합니다.

-S suffix

다른 모든 옵션들이 적용된 후, 가능한 각 자동 완성 후보의 끝부분에 suffix를 추가합니다.

-W wordlist

IFS 특수 변수의 문자들을 구분자로 사용하여 wordlist를 분할하고, 결과로 나온 각 단어를 확장합니다. 단어들이 쉘 메타 문자나 IFS 값에 포함된 문자들을 포함할 수 있도록 wordlist 내의 쉘 인용 규칙을 준수합니다. 가능한 자동 완성 후보들은 결과 목록 중 완성 중인 단어의 접두사와 일치하는 항목들입니다.

-X filterpat

filterpat은 파일 이름 확장에서 사용되는 것과 같은 패턴입니다. 이전의 옵션과 인자들에 의해 생성된 가능한 자동 완성 후보 목록에 적용되며, filterpat과 일치하는 각 완성 후보는 목록에서 제거됩니다. filterpat 시작 부분의 ‘!’는 패턴을 부정합니다; 이 경우 filterpat과 일치하지 않는 모든 완성 후보가 제거됩니다.

반환 값은 잘못된 옵션이 제공된 경우, -p, -r, -D, -E, 또는 -I 이외의 옵션이 name 인자 없이 제공된 경우, 자동 완성 사양이 존재하지 않는 name에 대해 사양 제거를 시도한 경우, 또는 자동 완성 사양 추가 중에 에러가 발생한 경우를 제외하고 참(true)입니다.

compopt ¶
compopt [-o option] [-DEI] [+o option] [name]

각 name에 대한 자동 완성 옵션들을 수정하거나, name이 주어지지 않은 경우 현재 실행 중인 자동 완성에 대해 수정합니다. 만약 option들이 주어지지 않으면, 각 name 또는 현재 자동 완성에 대한 옵션들을 표시합니다. 가능한 option 값들은 위에서 설명한 complete 빌트인에서 유효한 것들입니다.

-D 옵션은 제공된 다른 옵션들이 “기본(default)” 명령어 자동 완성에 적용되어야 함을 나타냅니다; -E 옵션은 “빈(empty)” 명령어 자동 완성에, 그리고 -I 옵션은 줄의 첫 단어에 대한 자동 완성에 적용됨을 나타냅니다. 이들은 complete 빌트인과 동일한 방식으로 결정됩니다.

여러 옵션이 제공되면 -D 옵션이 -E보다 우선하고, 둘 다 -I보다 우선합니다.

반환 값은 잘못된 옵션이 제공되거나, 자동 완성 사양이 존재하지 않는 name에 대해 옵션 수정을 시도하거나, 출력 에러가 발생한 경우를 제외하고 참(true)입니다.
