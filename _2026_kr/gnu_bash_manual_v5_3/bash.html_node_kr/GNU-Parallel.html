3.2.7 GNU Parallel ¶

Bash에 내장되어 있지는 않지만 명령어를 병렬(parallel)로 실행하는 방법들이 있습니다. GNU Parallel은 바로 그런 일을 수행하는 도구입니다.

GNU Parallel은 그 이름에서 알 수 있듯이, 명령어를 병렬로 구성하고 실행하는 데 사용될 수 있습니다. 파일 이름, 사용자 이름, 호스트 이름, 또는 파일에서 읽어 들인 줄 등 서로 다른 인자들을 사용하여 동일한 명령어를 실행할 수 있습니다. GNU Parallel은 가장 흔한 여러 작업들(입력 줄 처리, 입력 줄의 다양한 부분 추출, 입력 소스 지정의 다양한 방법 등)에 대해 축약된 참조 방식을 제공합니다. Parallel은 xargs를 대체하거나 입력 소스로부터 받은 명령어들을 여러 개의 서로 다른 Bash 인스턴스로 전달할 수 있습니다.

전체 설명은 다음 위치에서 이용 가능한 GNU Parallel 문서를 참조하십시오: https://www.gnu.org/software/parallel/parallel_tutorial.html.
