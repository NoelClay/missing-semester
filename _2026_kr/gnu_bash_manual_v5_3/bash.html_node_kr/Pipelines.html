3.2.3 파이프라인 ¶

파이프라인은 제어 연산자 ‘|’ 또는 ‘|&’로 구분된 하나 이상의 명령어 시퀀스입니다.

파이프라인의 형식은 다음과 같습니다: 

[time [-p]] [!] command1 [ | 또는 |& command2 ] ...

파이프라인 내의 각 명령어의 출력은 파이프를 통해 다음 명령어의 입력으로 연결됩니다. 즉, 각 명령어는 이전 명령어의 출력을 읽습니다. 이 연결은 command1에 지정된 그 어떤 리다이렉션보다도 먼저 수행됩니다.

파이프라인 연산자가 ‘|&’인 경우, command1의 표준 출력뿐만 아니라 표준 에러도 파이프를 통해 command2의 표준 입력으로 연결됩니다. 이는 2>&1 |의 축약형입니다. 표준 에러를 표준 출력으로 리다이렉션하는 이 암시적인 처리는 해당 축약형과 일관되게 command1에 지정된 리다이렉션이 수행된 이후에 이루어집니다.

예약어 time이 파이프라인 앞에 오면, Bash는 파이프라인이 종료된 후 실행 소요 시간 통계를 출력합니다. 현재 통계는 경과 시간(실제 시간)과 명령어 실행에 소요된 사용자 및 시스템 시간으로 구성됩니다. -p 옵션은 출력 형식을 POSIX에 지정된 형식으로 변경합니다. 쉘이 POSIX 모드(Bash와 POSIX 참조)일 때, 다음 토큰이 ‘-’로 시작하면 time을 예약어로 인식하지 않습니다. TIMEFORMAT 변수의 값은 시간 정보가 표시되는 방식을 지정하는 형식 문자열입니다. 사용 가능한 형식에 대한 설명은 Bash 변수를 참조하십시오. time을 예약어로 제공함으로써 쉘 빌트인, 쉘 함수, 파이프라인의 실행 시간을 측정할 수 있습니다. 외부 time 명령어로는 이들의 시간을 쉽게 측정할 수 없습니다.

쉘이 POSIX 모드(Bash와 POSIX 참조)일 때, time을 단독으로 단순 명령어로 사용할 수 있습니다. 이 경우 쉘은 쉘 자체와 그 자식 프로세스들이 소비한 총 사용자 및 시스템 시간을 표시합니다. TIMEFORMAT 변수가 시간 정보의 형식을 지정합니다.

파이프라인이 비동기적으로 실행되지 않는 한(명령어 목록 참조), 쉘은 파이프라인의 모든 명령어가 완료될 때까지 기다립니다.

파이프가 생성되는 다중 명령어 파이프라인의 각 명령어는 별도의 프로세스인 고유한 서브쉘(subshell)에서 실행됩니다(명령어 실행 환경 참조). 만약 shopt 빌트인(Shopt 빌트인 참조)을 사용하여 lastpipe 옵션을 활성화하고 작업 제어가 활성 상태가 아니라면, 파이프라인의 마지막 요소가 쉘 프로세스에 의해 실행될 수 있습니다.

파이프라인의 종료 상태는 pipefail 옵션이 활성화되어 있지 않는 한 파이프라인의 마지막 명령어의 종료 상태입니다(Set 빌트인 참조). pipefail이 활성화된 경우, 파이프라인의 반환 상태는 0이 아닌 상태로 종료된 마지막(가장 오른쪽) 명령어의 값이거나, 모든 명령어가 성공적으로 종료된 경우 0이 됩니다. 예약어 ‘!’가 파이프라인 앞에 오면, 종료 상태는 위에서 설명한 종료 상태의 논리적 부정(logical negation)이 됩니다. 파이프라인이 비동기적으로 실행되지 않는 한(명령어 목록 참조), 쉘은 값을 반환하기 전에 파이프라인의 모든 명령어가 종료될 때까지 기다립니다. 비동기 파이프라인의 반환 상태는 0입니다.
