3.7.1 단순 명령어 확장 ¶

쉘은 단순 명령어를 실행할 때, 왼쪽에서 오른쪽 방향으로 다음의 확장, 할당 및 리다이렉션을 순서대로 수행합니다.

  1. 파서(parser)가 변수 할당(명령어 이름 앞에 오는 단어들) 및 리다이렉션으로 표시한 단어들을 나중에 처리하기 위해 따로 저장해 둡니다.
  2. 변수 할당이나 리다이렉션이 아닌 단어들을 확장합니다(쉘 확장 참조). 확장 후에 단어가 남아있다면, 첫 번째 단어를 명령어 이름으로 간주하고 나머지 단어들을 인자로 취급합니다.
  3. 이전에 설명한 대로 리다이렉션을 수행합니다(리다이렉션 참조).
  4. 각 변수 할당문의 ‘=’ 뒤에 오는 텍스트는 변수에 할당되기 전에 물결표 확장, 파라미터 확장, 명령어 치환, 산술 확장, 그리고 따옴표 제거 과정을 거칩니다.

만약 명령어 이름이 결과로 나오지 않는다면, 변수 할당은 현재 쉘 환경에 영향을 미칩니다. 그러한 명령어(할당문과 리다이렉션으로만 구성된 명령어)의 경우, 할당문이 리다이렉션보다 먼저 수행됩니다. 그렇지 않은 경우(명령어 이름이 있는 경우), 변수들은 실행될 명령어의 환경(environment)에 추가되며 현재 쉘 환경에는 영향을 주지 않습니다. 만약 할당문 중 하나가 읽기 전용(readonly) 변수에 값을 할당하려고 시도하면 에러가 발생하고 명령어는 0이 아닌 상태로 종료됩니다.

명령어 이름이 결과로 나오지 않는 경우 리다이렉션이 수행되지만, 현재 쉘 환경에는 영향을 주지 않습니다. 리다이렉션 에러가 발생하면 명령어는 0이 아닌 상태로 종료됩니다.

확장 후에 명령어 이름이 남아있다면 아래 설명된 대로 실행이 진행됩니다. 그렇지 않으면 명령어가 종료됩니다. 만약 확장 과정 중 하나에 명령어 치환이 포함되어 있었다면, 해당 명령어의 종료 상태는 마지막으로 수행된 명령어 치환의 종료 상태가 됩니다. 명령어 치환이 없었다면 명령어는 0 상태로 종료됩니다.
