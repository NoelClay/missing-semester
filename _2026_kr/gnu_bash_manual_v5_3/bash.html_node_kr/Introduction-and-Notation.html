8.1 라인 편집 소개 ¶

다음 문단들에서는 키 입력(keystrokes)을 나타내는 표기법을 설명하기 위해 Emacs 스타일을 사용합니다.

C-k 표기법은 ‘Control-K’로 읽으며, Control 키를 누른 상태에서 k 키를 눌렀을 때 생성되는 문자를 설명합니다.

M-k 표기법은 ‘Meta-K’로 읽으며, Meta 키(있는 경우)를 누른 상태에서 k 키를 눌러(메타 문자) 생성된 후 두 키를 모두 떼었을 때의 문자를 설명합니다. Meta 키는 많은 키보드에서 ALT 또는 Option으로 표시되어 있습니다. 두 개의 ALT 키가 있는 키보드(보통 스페이스 바의 양옆)에서는 일반적으로 왼쪽의 ALT 키가 Meta 키로 작동하도록 설정되어 있습니다. ALT 키 중 하나는 액센트가 붙은 문자를 입력하기 위한 Compose 키와 같은 다른 수식 키(modifier)로 구성될 수도 있습니다.

일부 키보드에서 Meta 수식 키는 여덟 번째 비트(0200)가 설정된 문자를 생성합니다. 키보드가 이를 허용하는 경우 enable-meta-key 변수를 사용하여 이 동작 여부를 제어할 수 있습니다. 다른 많은 경우, 터미널이나 터미널 에뮬레이터는 메타화된(metafied) 키를 다음 문단에서 설명하는 대로 ESC로 시작하는 키 시퀀스로 변환합니다.

만약 Meta 키나 ALT 키, 또는 Meta 키로 작동하는 다른 키가 없다면, 일반적으로 ESC를 먼저 누른 다음 k를 입력함으로써 동일한 효과를 얻을 수 있습니다. ESC 문자는 메타 접두사(meta prefix)라고 알려져 있습니다.

어느 쪽이든 이 과정을 k 키를 메타화(metafying)한다고 부릅니다.

만약 Meta 키가 ESC 메타 접두사를 포함하는 키 시퀀스를 생성한다면, force-meta-prefix 변수를 설정하여 직접 지정한 M-key 키 바인딩(Readline 초기화 파일 문법의 키 바인딩 참조)이 동일하게 작동하도록 만들 수 있습니다.

M-C-k 표기법은 ‘Meta-Control-k’로 읽으며, C-k를 메타화하여 생성된 문자를 설명합니다.

추가로, 여러 키들은 고유한 이름을 가지고 있습니다. 구체적으로 DEL, ESC, LFD, SPC, RET, 그리고 TAB은 본문이나 초기화 파일(Readline 초기화 파일 참조)에서 쓰일 때 해당 키 자체를 의미합니다. 만약 키보드에 LFD 키가 없다면 C-j를 입력하여 해당 문자를 출력할 수 있습니다. RET 키는 일부 키보드에서 Return 또는 Enter로 표시되어 있을 수 있습니다.
