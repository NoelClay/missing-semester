8.4.3 텍스트 변경 명령어 ¶

end-of-file (보통 C-d) ¶

stty 등으로 설정된 파일 끝(EOF)을 나타내는 문자입니다. 줄에 아무 글자도 없고 포인트가 줄의 시작 부분에 있을 때 이 문자가 읽히면, Readline은 이를 입력의 끝으로 해석하고 EOF를 반환합니다.

delete-char (C-d) ¶

포인트 위치의 문자를 삭제합니다. 이 함수가 tty EOF 문자와 동일한 키에 바인딩된 경우(흔히 C-d가 그러함), 그 효과에 대해서는 위를 참조하십시오. 일부 키보드의 Delete 키에 바인딩되어 있을 수 있습니다.

backward-delete-char (Rubout) ¶

커서 뒤의 문자를 삭제합니다. 숫자 인자가 제공되면 문자를 단순히 삭제하는 대신 킬링 버퍼(kill ring)에 저장(kill)합니다.

forward-backward-delete-char () ¶

커서 아래의 문자를 삭제합니다. 단, 커서가 줄의 끝에 있다면 커서 뒤의 문자를 삭제합니다. 기본적으로 바인딩되어 있지 않습니다.

quoted-insert (C-q 또는 C-v) ¶

다음에 입력되는 문자를 문자 그대로(verbatim) 줄에 추가합니다. 예를 들어 C-q와 같은 키 시퀀스를 삽입할 때 사용합니다.

self-insert (a, b, A, 1, !, …) ¶

입력된 문자를 삽입합니다.

bracketed-paste-begin () ¶

이 함수는 일부 터미널에서 보내는 "bracketed paste" 이스케이프 시퀀스에 바인딩되도록 설계되었으며, 기본적으로 해당 바인딩이 할당되어 있습니다. 이는 Readline이 붙여넣은 텍스트의 각 문자를 키보드 입력을 처리하듯이 하나씩 처리하지 않고 단일 단위로 삽입할 수 있게 해줍니다. 문자들은 편집 명령어를 실행하는 대신 마치 각 문자가 self-insert에 바인딩된 것처럼 삽입됩니다.

브래킷 붙여넣기(Bracketed paste)는 리전(region, 포인트와 마크 사이의 문자들)을 삽입된 텍스트로 설정하며, 활성 리전(active region)으로 만듭니다.

transpose-chars (C-t) ¶

커서 앞의 문자를 커서 위치의 문자 뒤로 끌어다 놓으며, 커서도 함께 앞으로 이동시킵니다. 삽입 지점이 줄의 끝에 있다면 줄의 마지막 두 문자의 위치를 서로 바꿉니다. 음수 인자는 아무런 효과가 없습니다.

transpose-words (M-t) ¶

포인트 앞의 단어를 포인트 뒤의 단어 너머로 끌어다 놓으며, 포인트도 해당 단어 너머로 이동시킵니다. 삽입 지점이 줄의 끝에 있다면 줄의 마지막 두 단어의 위치를 서로 바꿉니다.

shell-transpose-words (M-C-t) ¶

포인트 앞의 단어를 포인트 뒤의 단어 너머로 끌어다 놓으며, 포인트도 해당 단어 너머로 이동시킵니다. 삽입 지점이 줄의 끝에 있다면 줄의 마지막 두 단어의 위치를 서로 바꿉니다. 단어 경계는 shell-forward-word 및 shell-backward-word와 동일합니다.

upcase-word (M-u) ¶

현재(또는 뒤따르는) 단어를 대문자로 변환합니다. 음수 인자가 제공되면 이전 단어를 대문자로 변환하지만 커서는 이동하지 않습니다.

downcase-word (M-l) ¶

현재(또는 뒤따르는) 단어를 소문자로 변환합니다. 음수 인자가 제공되면 이전 단어를 소문자로 변환하지만 커서는 이동하지 않습니다.

capitalize-word (M-c) ¶

현재(또는 뒤따르는) 단어의 첫 글자를 대문자로 변환합니다. 음수 인자가 제공되면 이전 단어의 첫 글자를 대문자로 변환하지만 커서는 이동하지 않습니다.

overwrite-mode () ¶

겹쳐쓰기(overwrite) 모드를 토글합니다. 명시적인 양수 숫자 인자가 주어지면 겹쳐쓰기 모드로 전환합니다. 명시적인 0 이하의 숫자 인자가 주어지면 삽입(insert) 모드로 전환합니다. 이 명령어는 emacs 모드에만 영향을 줍니다; vi 모드는 다른 방식으로 겹쳐쓰기를 수행합니다. 각 readline() 호출은 삽입 모드에서 시작합니다.

겹쳐쓰기 모드에서 self-insert에 바인딩된 문자들은 텍스트를 오른쪽으로 밀어내는 대신 포인트 위치의 기존 텍스트를 대체합니다. backward-delete-char에 바인딩된 문자들은 포인트 앞의 문자를 공백으로 대체합니다.

기본적으로 바인딩되어 있지 않지만, 일부 키보드의 Insert 키에 바인딩되어 있을 수 있습니다.
