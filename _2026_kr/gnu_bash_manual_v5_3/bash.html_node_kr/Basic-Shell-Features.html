3 기본 쉘 기능 ¶

Bash는 ‘Bourne-Again SHell’의 약자입니다. Bourne 쉘은 원래 Stephen Bourne이 작성한 전통적인 유닉스 쉘입니다. Bourne 쉘의 모든 빌트인 명령어를 Bash에서 사용할 수 있으며, 평가 및 인용 규칙은 ‘표준’ 유닉스 쉘에 대한 POSIX 사양에서 가져왔습니다.

이 장에서는 쉘의 ‘구성 요소’들을 간략하게 요약합니다: 명령어, 제어 구조, 쉘 함수, 쉘 파라미터, 쉘 확장, 지정된 파일로 입출력을 보내거나 받는 방법인 리다이렉션, 그리고 쉘이 명령어를 실행하는 방식에 대해 설명합니다.
