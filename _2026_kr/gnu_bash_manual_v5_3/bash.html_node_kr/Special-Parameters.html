3.4.2 특수 파라미터 ¶

쉘은 여러 파라미터들을 특별하게 취급합니다. 이 파라미터들은 오직 참조만 가능하며, 값을 할당하는 것은 허용되지 않습니다. 특수 파라미터들은 다음 문자들 중 하나로 나타냅니다.

* ¶

($*) 1번부터 시작하는 위치 파라미터들로 확장됩니다. 확장이 큰따옴표 내에서 이루어지지 않을 때, 각 위치 파라미터는 별개의 단어로 확장됩니다. 단어 확장이 수행되는 컨텍스트에서, 해당 단어들은 추가적인 단어 분할과 파일 이름 확장의 대상이 됩니다. 확장이 큰따옴표 내에서 이루어질 때, IFS 변수의 첫 번째 문자로 각 파라미터 값이 구분된 단일 단어로 확장됩니다. 즉, "$*"은 "$1c$2c…"와 동일하며, 여기서 c는 IFS 변수값의 첫 번째 문자입니다. 만약 IFS가 설정되어 있지 않으면 파라미터들은 공백으로 구분됩니다. 만약 IFS가 null(빈 값)이면 파라미터들은 사이에 구분자 없이 연결됩니다.

@ ¶

($@) 1번부터 시작하는 위치 파라미터들로 확장됩니다. 단어 분할이 수행되는 컨텍스트에서, 이는 각 위치 파라미터를 별개의 단어로 확장합니다. 큰따옴표 내에 있지 않은 경우, 이 단어들은 단어 분할의 대상이 됩니다. 할당문의 값 부분과 같이 단어 분할이 수행되지 않는 컨텍스트에서, 이는 각 위치 파라미터가 공백으로 구분된 단일 단어로 확장됩니다. 확장이 큰따옴표 내에서 이루어지고 단어 분할이 수행될 때, 각 파라미터는 별개의 단어로 확장됩니다. 즉, "$@"는 "$1" "$2" …와 동일합니다. 큰따옴표로 감싸진 확장이 어떤 단어 내부에서 일어날 경우, 첫 번째 파라미터의 확장 결과는 원래 단어의 앞부분 확장 결과와 결합되고, 마지막 파라미터의 확장 결과는 원래 단어의 뒷부분 확장 결과와 결합됩니다. 위치 파라미터가 없는 경우, "$@"와 $@는 아무것도 없는 상태로 확장됩니다(즉, 제거됩니다).

# ¶

($#) 위치 파라미터의 개수를 10진수로 확장합니다.

? ¶

($?) 가장 최근에 실행된 명령어의 종료 상태로 확장됩니다.

- ¶

($-, 하이픈) 호출 시 지정되었거나, set 빌트인 명령어로 설정되었거나, 혹은 쉘 자체에 의해 설정된(예: -i 옵션) 현재 옵션 플래그들로 확장됩니다.

$ ¶

($$) 쉘의 프로세스 ID로 확장됩니다. 서브쉘 내에서도 서브쉘의 ID가 아닌, 이를 호출한 쉘의 프로세스 ID로 확장됩니다.

! ¶

($!) 비동기 명령어로 실행되었거나 bg 빌트인을 사용하여 가장 최근에 백그라운드로 보내진 작업의 프로세스 ID로 확장됩니다(작업 제어 빌트인 참조).

0 ¶

($0) 쉘 또는 쉘 스크립트의 이름으로 확장됩니다. 이는 쉘 초기화 시에 설정됩니다. Bash가 명령어 파일과 함께 호출된 경우(쉘 스크립트 참조), $0은 해당 파일의 이름으로 설정됩니다. Bash가 -c 옵션과 함께 시작된 경우(Bash 호출하기 참조), $0은 실행할 문자열 뒤에 오는 첫 번째 인자(있는 경우)로 설정됩니다. 그렇지 않은 경우, 0번 인자로 주어지는 Bash 호출에 사용된 파일명으로 설정됩니다.
