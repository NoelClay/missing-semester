8.5 Readline vi 모드 ¶

Readline 라이브러리가 vi의 모든 편집 기능 세트를 가지고 있는 것은 아니지만, 줄에 대한 간단한 편집을 수행하기에는 충분한 기능들을 포함하고 있습니다. Readline vi 모드는 POSIX 표준의 sh 설명에 명시된 대로 동작합니다.

‘set -o emacs’ 및 ‘set -o vi’ 명령어를 사용하여(Set 빌트인 참조) emacs와 vi 편집 모드 사이를 대화형으로 전환할 수 있습니다. Readline의 기본값은 emacs 모드입니다.

vi 모드에서 줄을 입력하기 시작할 때, 사용자는 마치 ‘i’를 입력한 것처럼 이미 ‘삽입(insertion)’ 모드에 놓여 있습니다. ESC 키를 누르면 ‘명령어(command)’ 모드로 전환되며, 여기서 표준 vi 이동 키들을 사용하여 줄의 텍스트를 편집하거나, ‘k’를 사용하여 이전 히스토리 줄로, ‘j’를 사용하여 이후 줄로 이동하는 등의 작업을 수행할 수 있습니다.
