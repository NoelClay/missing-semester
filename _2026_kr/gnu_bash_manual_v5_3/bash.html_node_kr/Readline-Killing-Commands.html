8.2.3 Readline 삭제(Killing) 명령어 ¶

텍스트를 삭제(Killing)한다는 것은 줄에서 텍스트를 지우되, 나중에 붙여넣기(yanking, 다시 삽입하기)를 통해 사용할 수 있도록 따로 저장해 두는 것을 의미합니다. (‘잘라내기(cut)’와 ‘붙여넣기(paste)’는 ‘삭제(kill)’와 ‘양킹(yank)’에 대한 보다 현대적인 용어입니다.)

어떤 명령어에 대한 설명이 텍스트를 ‘삭제(kill)’한다고 되어 있다면, 나중에 다른 곳(또는 같은 곳)에서 해당 텍스트를 다시 불러올 수 있음을 확신해도 좋습니다.

삭제 명령어를 사용하면 텍스트는 킬링(kill-ring) 버퍼에 저장됩니다. 연속적으로 수행된 여러 번의 삭제 작업은 삭제된 모든 텍스트를 함께 저장하므로, 나중에 붙여넣을 때 한꺼번에 가져올 수 있습니다. 킬링 버퍼는 현재 줄에만 국한되지 않습니다; 이전에 입력했던 줄에서 삭제한 텍스트도 나중에 다른 줄을 입력할 때 붙여넣을 수 있습니다.

다음은 텍스트를 삭제하는 명령어 목록입니다.

C-k

현재 커서 위치부터 줄 끝까지 텍스트를 삭제.

M-d

커서 위치부터 현재 단어의 끝까지, 또는 단어 사이인 경우 다음 단어의 끝까지 삭제. 단어 경계는 M-f에서 사용되는 것과 동일합니다.

M-DEL

커서 위치부터 현재 단어의 시작까지, 또는 단어 사이인 경우 이전 단어의 시작까지 삭제. 단어 경계는 M-b에서 사용되는 것과 동일합니다.

C-w

커서 위치부터 이전 공백(whitespace)까지 삭제. 단어 경계 기준이 다르기 때문에 M-DEL과는 다릅니다.

다음은 텍스트를 붙여넣는(yank) 방법입니다. 양킹(Yanking)은 킬링 버퍼에서 가장 최근에 삭제된 텍스트를 현재 커서 위치의 줄에 복사하는 것을 의미합니다.

C-y

가장 최근에 삭제된 텍스트를 커서 위치의 버퍼에 붙여넣음.

M-y

킬링(kill-ring) 버퍼를 회전시키고 새로운 최상단 항목을 붙여넣음. 이 명령어는 바로 이전 명령어가 C-y 또는 M-y인 경우에만 사용할 수 있습니다.
