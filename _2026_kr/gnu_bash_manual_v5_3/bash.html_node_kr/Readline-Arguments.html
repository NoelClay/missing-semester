8.2.4 Readline 인자 (Readline Arguments) ¶

Readline 명령어에 숫자 인자(numeric arguments)를 전달할 수 있습니다. 때로는 인자가 반복 횟수(repeat count)로 작동하고, 다른 때는 인자의 부호(sign)가 중요한 의미를 갖습니다. 보통 앞으로(순방향) 작용하는 명령어에 음수 인자를 전달하면, 해당 명령어는 뒤로(역방향) 작용하게 됩니다. 예를 들어, 현재 위치에서 줄의 시작 부분까지 텍스트를 삭제하려면 ‘M-- C-k’를 입력하면 됩니다.

명령어에 숫자 인자를 전달하는 일반적인 방법은 명령어 앞에 Meta 숫자를 입력하는 것입니다. 처음 입력한 ‘숫자’가 마이너스 기호(‘-’)라면 인자의 부호는 음수가 됩니다. 인자를 시작하기 위해 하나의 Meta 숫자를 입력한 후에는 나머지 숫자들을 입력하고 마지막으로 명령어를 입력하면 됩니다. 예를 들어, C-d 명령어에 인자 10을 주려면 ‘M-1 0 C-d’라고 입력하면 되며, 이는 입력줄에서 다음 10개의 문자를 삭제합니다.
