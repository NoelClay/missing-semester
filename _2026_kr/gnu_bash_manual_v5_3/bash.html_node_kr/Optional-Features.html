10.8 선택적 기능 (Optional Features) ¶

Bash configure는 많은 --enable-feature 옵션들을 가지고 있으며, 여기서 feature는 Bash의 선택적 부분을 나타냅니다. 또한 여러 --with-package 옵션들이 있으며, package는 ‘bash-malloc’ 또는 ‘afs’와 같은 것들입니다. 패키지의 기본 사용을 끄려면 --without-package를 사용하십시오. 기본적으로 활성화된 기능을 제외하고 Bash를 구성하려면 --disable-feature를 사용하십시오.

다음은 Bash configure가 인식하는 --enable- 및 --with- 옵션들의 전체 목록입니다.

--with-afs

Transarc의 Andrew File System을 사용 중인 경우 정의하십시오.

--with-bash-malloc

lib/malloc 디렉토리에 있는 Bash 버전의 malloc을 사용합니다. 이는 GNU libc에 포함된 malloc과는 다르며, 원래 4.2 BSD malloc으로부터 파생된 커스텀 버전입니다. 이 malloc은 매우 빠르지만 할당 시마다 약간의 공간을 낭비합니다. 물론 낭비를 최소화하기 위해 여러 기술을 사용합니다. 이 옵션은 기본적으로 활성화되어 있습니다. NOTES 파일에는 이 옵션을 꺼야 하는 시스템 목록이 포함되어 있으며, configure는 여러 시스템에서 이 옵션을 자동으로 비활성화합니다.

--with-curses

termcap 라이브러리 대신 curses 라이브러리를 사용합니다. 대부분의 시스템이 curses 라이브러리에 termcap 함수들을 포함하고 있으므로, configure는 대개 이를 자동으로 선택합니다.

--with-gnu-malloc

--with-bash-malloc의 동의어입니다.

--with-installed-readline[=PREFIX]

Bash가 lib/readline에 있는 버전 대신 로컬에 설치된 Readline 버전을 링크하도록 정의합니다. 이는 Readline 5.0 및 이후 버전에서만 작동합니다. 만약 PREFIX가 yes이거나 주어지지 않은 경우, configure는 설치된 Readline 버전이 표준 시스템 인클루드 및 라이브러리 디렉토리에 없다면 이를 찾기 위해 includedir 및 libdir(기본적으로 prefix의 하위 디렉토리임)의 값을 사용합니다. 만약 PREFIX가 no이면, Bash는 lib/readline에 있는 버전과 링크합니다. 만약 PREFIX가 그 외의 값으로 설정되면, configure는 이를 디렉토리 경로로 간주하고 해당 디렉토리의 하위 디렉토리(헤더 파일은 PREFIX/include, 라이브러리는 PREFIX/lib)에서 설치된 Readline 버전을 찾습니다. Bash의 기본값은 빌드 디렉토리의 lib/readline 하위 디렉토리에 빌드된 정적 라이브러리와 링크하는 것입니다.

--with-libintl-prefix[=PREFIX]

Bash가 lib/intl에 있는 버전 대신 로컬에 설치된 libintl 라이브러리 버전과 링크하도록 정의합니다.

--with-libiconv-prefix[=PREFIX]

Bash가 표준 시스템 위치 대신 PREFIX에서 libiconv를 찾도록 정의합니다. Bash 배포판은 이 라이브러리를 포함하지 않습니다.

--enable-minimal-config

역사적인 Bourne 쉘에 더 가까운, 최소한의 기능을 가진 쉘을 생성합니다.

런타임 기능을 변경하기보다 Bash가 컴파일, 링크, 그리고 설치되는 방식을 변경하는 여러 --enable- 옵션들이 있습니다.

--enable-largefile

대용량 파일에 접근할 수 있는 프로그램을 빌드하기 위해 운영체제가 특별한 컴파일러 옵션을 요구하는 경우, 대용량 파일(large files) 지원을 활성화합니다. 운영체제가 대용량 파일 지원을 제공한다면 이 옵션은 기본적으로 활성화됩니다.

--enable-profiling

실행될 때마다 gprof에 의해 처리될 프로파일링 정보를 생성하는 Bash 바이너리를 빌드합니다.

--enable-separate-helpfiles

help 빌트인에 의해 표시되는 문서를 내부에 저장하는 대신 외부 파일을 사용합니다.

--enable-static-link

gcc를 사용 중인 경우 Bash를 정적으로 링크(statically link)하게 합니다. 이는 루트(root)의 쉘로 사용할 버전을 빌드할 때 쓰일 수 있습니다.

‘minimal-config’ 옵션은 아래의 모든 옵션들을 비활성화하는 데 사용될 수 있지만, 가장 먼저 처리되므로 개별 옵션들을 ‘enable-feature’를 사용하여 다시 활성화할 수 있습니다.

‘alt-array-implementation’, ‘disabled-builtins’, ‘direxpand-default’, ‘strict-posix-default’, 그리고 ‘xpg-echo-default’를 제외한 다음의 모든 옵션들은 운영체제가 필요한 지원을 제공하지 않는 경우를 제외하고 기본적으로 활성화되어 있습니다.

--enable-alias

별칭 확장(alias expansion)을 허용하고 alias 및 unalias 빌트인을 포함합니다(별칭 참조).

--enable-alt-array-implementation

더 많은 메모리를 사용하는 대신(배열이 얼마나 희소한지에 따라 때로는 몇 배 더 많이 사용함) 더 빠른 접근을 제공하는 배열의 대체 구현을 사용하여 Bash를 빌드합니다(배열 참조).

--enable-arith-for-command

C 언어의 for 문처럼 동작하는 for 명령어의 대체 형식을 포함합니다(루프 구조 참조).

--enable-array-variables

1차원 배열 쉘 변수 지원을 포함합니다(배열 참조).

--enable-bang-history

csh 스타일의 히스토리 치환 지원을 포함합니다(히스토리 확장 참조).

--enable-bash-source-fullpath-default

위의 Shopt 빌트인에서 설명한 bash_source_fullpath 쉘 옵션의 기본값을 활성화 상태로 설정합니다. 이는 파일 이름이 BASH_SOURCE 배열 변수에 어떻게 할당되는지를 제어합니다.

--enable-brace-expansion

csh 스타일의 중괄호 확장을 포함합니다(b{a,b}c → bac bbc). 전체 설명은 중괄호 확장을 참조하십시오.

--enable-casemod-attributes

declare 빌트인 및 할당문에서 대소문자 수정 속성(case-modifying attributes) 지원을 포함합니다. 예를 들어 uppercase 속성을 가진 변수는 할당 시 값이 대문자로 변환됩니다.

--enable-casemod-expansion

대소문자 수정 단어 확장(case-modifying word expansions) 지원을 포함합니다.

--enable-command-timing

time을 예약어로 인식하고 time 뒤에 오는 파이프라인에 대한 타이밍 통계를 표시하는 기능을 포함합니다(파이프라인 참조). 이는 외부 명령어가 쉽게 할 수 없는 파이프라인, 쉘 복합 명령어, 쉘 빌트인, 그리고 쉘 함수의 시간을 측정할 수 있게 해줍니다.

--enable-cond-command

[[ 조건부 명령어 지원을 포함합니다(조건부 구조 참조).

--enable-cond-regexp

[[ 조건부 명령어에서 ‘=~’ 이항 연산자를 사용한 POSIX 정규 표현식 매칭 지원을 포함합니다(조건부 구조 참조).

--enable-coprocesses

코프로세스(coprocesses)와 coproc 예약어 지원을 포함합니다(파이프라인 참조).

--enable-debugger

Bash 디버거(별도로 배포됨) 지원을 포함합니다.

--enable-dev-fd-stat-broken

/dev/fd/N에 대해 stat을 호출한 결과가 파일 디스크립터 N에 대해 fstat을 호출한 결과와 다르다면, 이 옵션을 사용하여 우회책을 활성화하십시오. 이는 파일 속성을 테스트하는 조건부 명령어들에 영향을 미칩니다.

--enable-direxpand-default

쉘이 시작될 때 direxpand 쉘 옵션(Shopt 빌트인 참조)이 기본적으로 활성화되도록 합니다. 평소에는 기본적으로 비활성화되어 있습니다.

--enable-directory-stack

csh 스타일의 디렉토리 스택과 pushd, popd, 그리고 dirs 빌트인 지원을 포함합니다(디렉토리 스택 참조).

--enable-disabled-builtins

‘enable -n xxx’를 사용하여 xxx가 비활성화된 후에도 ‘builtin xxx’를 통해 빌트인 명령어를 호출할 수 있게 허용합니다. builtin 및 enable 빌트인 명령어에 대한 자세한 내용은 Bash 빌트인 명령어를 참조하십시오.

--enable-dparen-arithmetic

((…)) 명령어 지원을 포함합니다(조건부 구조 참조).

--enable-extended-glob

위의 패턴 매칭에서 설명한 확장된 패턴 매칭 기능들에 대한 지원을 포함합니다.

--enable-extended-glob-default

위의 Shopt 빌트인에서 설명한 extglob 쉘 옵션의 기본값을 활성화 상태로 설정합니다.

--enable-function-import

환경으로부터 쉘의 다른 인스턴스에 의해 내보내기(export)된 함수 정의를 가져오는(import) 기능을 포함합니다. 이 옵션은 기본적으로 활성화되어 있습니다.

--enable-glob-asciiranges-default

위의 Shopt 빌트인에서 설명한 globasciiranges 쉘 옵션의 기본값을 활성화 상태로 설정합니다. 이는 패턴 매칭 브래킷 표현식에서 사용되는 문자 범위(character ranges)의 동작을 제어합니다.

--enable-help-builtin

쉘 빌트인 및 변수들에 대한 도움말을 표시하는 help 빌트인을 포함합니다(Bash 빌트인 명령어 참조).

--enable-history

명령어 히스토리와 fc 및 history 빌트인 명령어를 포함합니다(Bash 히스토리 기능 참조).

--enable-job-control

운영체제가 지원하는 경우 작업 제어(job control) 기능들을 활성화합니다(작업 제어 참조).

--enable-multibyte

운영체제가 필요한 지원을 제공하는 경우 다중 바이트 문자(multibyte characters) 지원을 활성화합니다.

--enable-net-redirections

리다이렉션에서 사용되는 /dev/tcp/host/port 및 /dev/udp/host/port 형식의 파일 이름들에 대한 특별한 처리를 활성화합니다(리다이렉션 참조).

--enable-process-substitution

운영체제가 필요한 지원을 제공하는 경우 프로세스 치환(process substitution)을 활성화합니다(프로세스 치환 참조).

--enable-progcomp

프로그래밍 가능한 자동 완성(programmable completion) 시설을 활성화합니다(프로그래밍 가능한 자동 완성 참조). Readline이 활성화되어 있지 않으면 이 옵션은 효과가 없습니다.

--enable-prompt-string-decoding

$PS0, $PS1, $PS2, 그리고 $PS4 프롬프트 문자열에서 여러 백슬래시 이스케이프 문자들에 대한 해석을 켭니다. 프롬프트 문자열 이스케이프 시퀀스의 전체 목록은 프롬프트 제어하기를 참조하십시오.

--enable-readline

Bash 버전의 Readline 라이브러리를 사용하여 명령줄 편집 및 히스토리 지원을 포함합니다(명령줄 편집 참조).

--enable-restricted

제한된 쉘(restricted shell) 지원을 포함합니다. 이 기능이 활성화되면 Bash가 rbash로 호출되었을 때 제한 모드로 진입합니다. 제한 모드에 대한 설명은 제한된 쉘을 참조하십시오.

--enable-select

간단한 메뉴 생성을 가능하게 하는 select 복합 명령어를 포함합니다(조건부 구조 참조).

--enable-single-help-strings

help 빌트인에 의해 표시되는 텍스트를 각 도움말 주제마다 단일 문자열로 저장합니다. 이는 텍스트를 다른 언어로 번역하는 데 도움을 줍니다. 컴파일러가 매우 긴 문자열 리터럴을 처리하지 못하는 경우 이 옵션을 비활성화해야 할 수도 있습니다.

--enable-strict-posix-default

Bash가 기본적으로 POSIX를 준수하도록 만듭니다(Bash와 POSIX 참조).

--enable-translatable-strings

$"string" 번역 가능한 문자열 지원을 활성화합니다(로케일 특정 번역 참조).

--enable-usg-echo-default

--enable-xpg-echo-default의 동의어입니다.

--enable-xpg-echo-default

echo 빌트인이 -e 옵션 없이도 기본적으로 백슬래시 이스케이프 문자들을 확장하게 만듭니다. 이는 xpg_echo 쉘 옵션의 기본값을 on으로 설정하며, 이는 Bash echo가 Single Unix Specification, 버전 3에 명시된 버전과 더 유사하게 동작하도록 만듭니다. echo가 인식하는 이스케이프 시퀀스에 대한 설명은 Bash 빌트인 명령어를 참조하십시오.

config-top.h 파일에는 configure에서 설정할 수 없는 옵션들을 위한 C 전처리기 ‘#define’ 문들이 포함되어 있습니다. 이들 중 일부는 변경해서는 안 됩니다; 변경하는 경우 그 결과에 주의하십시오. 각 정의의 효과에 대한 더 자세한 정보는 각 정의와 연관된 주석을 읽어보십시오.
