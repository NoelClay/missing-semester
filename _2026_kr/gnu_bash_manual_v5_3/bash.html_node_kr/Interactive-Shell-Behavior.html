6.3.3 대화형 쉘의 동작 ¶

쉘이 대화형으로 실행 중일 때, 다음과 같은 여러 가지 방식으로 동작이 변경됩니다.

  1. Bash는 Bash 시작 파일에 설명된 대로 시작 파일들을 읽고 실행합니다.
  2. 작업 제어(작업 제어 참조)가 기본적으로 활성화됩니다. 작업 제어가 활성 상태일 때, Bash는 키보드에서 생성된 작업 제어 시그널인 SIGTTIN, SIGTTOU, 그리고 SIGTSTP를 무시합니다.
  3. Bash는 기본 프롬프트인 $PS1을 출력하기 전에 PROMPT_COMMAND 배열 변수의 설정된 요소 값들을 명령어로 실행합니다(Bash 변수 참조).
  4. Bash는 명령어의 첫 번째 줄을 읽기 전에 PS1을 확장하여 표시하고, 여러 줄 명령어의 두 번째 이상의 줄을 읽기 전에는 PS2를 확장하여 표시합니다. Bash는 명령어를 읽은 후 실행하기 직전에 PS0을 확장하여 표시합니다. 프롬프트 문자열 이스케이프 시퀀스의 전체 목록은 프롬프트 제어하기를 참조하십시오.
  5. Bash는 사용자의 터미널로부터 명령어를 읽기 위해 Readline(명령줄 편집 참조)을 사용합니다.
  6. Bash는 명령어를 읽는 동안 표준 입력에서 EOF를 받았을 때 즉시 종료하는 대신, set -o의 ignoreeof 옵션 값을 확인합니다(Set 빌트인 참조).
  7. Bash는 명령어 히스토리(Bash 히스토리 기능 참조)와 히스토리 확장(히스토리 확장 참조)을 기본적으로 활성화합니다. 히스토리가 활성화된 쉘이 종료될 때, Bash는 $HISTFILE로 지정된 파일에 명령어 히스토리를 저장합니다.
  8. 별칭 확장(별칭 참조)이 기본적으로 수행됩니다.
  9. 트랩(trap)이 설정되어 있지 않은 경우, Bash는 SIGTERM을 무시합니다(시그널 참조).
  10. 트랩이 설정되어 있지 않은 경우, SIGINT를 포착하여 처리합니다(시그널 참조). SIGINT는 일부 쉘 빌트인 명령어를 중단시킵니다.
  11. huponexit 쉘 옵션이 활성화되어 있다면, 대화형 로그인 쉘은 종료 시 모든 작업(jobs)에게 SIGHUP을 보냅니다(시그널 참조).
  12. 호출 시나 ‘set -n’을 사용할 때 -n 옵션은 아무런 효과가 없습니다(Set 빌트인 참조).
  13. Bash는 MAIL, MAILPATH, 그리고 MAILCHECK 쉘 변수 값에 따라 주기적으로 메일을 확인합니다(Bash 변수 참조).
  14. ‘set -u’가 활성화된 후에도 설정되지 않은 쉘 변수 참조로 인한 확장 에러가 발생해도 쉘은 종료되지 않습니다(Set 빌트인 참조).
  15. ${var:?word} 확장 시 var가 해제되어 있거나 null이어서 발생하는 확장 에러로 인해 쉘이 종료되지 않습니다(쉘 파라미터 확장 참조).
  16. 쉘 빌트인 명령어 수행 중 발생한 리다이렉션 에러로 인해 쉘이 종료되지 않습니다.
  17. POSIX 모드에서 실행 중일 때, 특수 빌트인이 에러 상태를 반환하더라도 쉘이 종료되지 않습니다(Bash와 POSIX 참조).
  18. exec 실패로 인해 쉘이 종료되지 않습니다(Bourne 쉘 빌트인 참조).
  19. 파서의 문법 오류로 인해 쉘이 종료되지 않습니다.
  20. cdspell 쉘 옵션이 활성화되어 있다면, 쉘은 cd 빌트인의 디렉토리 인자에 대해 사소한 철자 수정을 시도합니다(Shopt 빌트인의 cdspell 옵션 설명 참조). cdspell 옵션은 오직 대화형 쉘에서만 유효합니다.
  21. 쉘은 TMOUT 변수 값을 확인하고, $PS1 출력 후 지정된 초 내에 명령어를 읽지 못하면 종료합니다(Bash 변수 참조).
