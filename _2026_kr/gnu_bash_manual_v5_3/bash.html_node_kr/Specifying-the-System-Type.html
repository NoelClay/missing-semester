10.5 시스템 유형 지정 ¶

configure가 자동으로 알아내지 못하지만, Bash가 실행될 호스트의 유형에 따라 결정해야 하는 몇몇 기능들이 있을 수 있습니다. 보통 configure는 이를 스스로 알아낼 수 있지만, 만약 호스트 유형을 추측할 수 없다는 메시지를 출력한다면 --host=TYPE 옵션을 사용하십시오. ‘TYPE’은 ‘sun4’와 같은 짧은 시스템 이름이거나, 세 개의 필드로 구성된 정규 이름(canonical name)인 ‘CPU-COMPANY-SYSTEM’ 형식(예: ‘i386-unknown-freebsd4.2’)일 수 있습니다.

각 필드에 사용 가능한 값들은 support/config.sub 파일을 참조하십시오.
