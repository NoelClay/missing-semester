1. 서론 (Introduction)

1.1 Bash란 무엇인가?

Bash는 GNU 운영체제의 쉘, 즉 명령 언어 해석기입니다. 이름은 'Bourne-Again SHell'의 약자로, 현재 유닉스 쉘 sh의 조상인 Stephen Bourne의 이름에서 유래한 유머 섞인 표현입니다.

Bash는 기존 sh와 높은 호환성을 유지하면서 ksh와 csh의 유용한 기능들을 포함하고 있습니다. IEEE POSIX 표준을 준수하며, 대화형 사용과 프로그래밍(스크립팅) 모두에서 기존 sh보다 강력한 기능을 제공합니다.

1.2 쉘이란 무엇인가?

가장 기본적으로 쉘은 명령어를 실행하는 매크로 프로세서입니다. 여기서 매크로 프로세서란 텍스트와 기호를 확장하여 더 복잡한 표현식을 만드는 기능을 말합니다.

유닉스 쉘은 명령어 해석기인 동시에 프로그래밍 언어이기도 합니다. 명령어 해석기로서는 사용자가 GNU 유틸리티들에 접근할 수 있는 인터페이스를 제공하고, 프로그래밍 언어로서는 이러한 유틸리티들을 조합하여 복잡한 작업을 자동화할 수 있게 해줍니다.

쉘은 대화형(키보드 입력) 또는 비대화형(파일/스크립트 실행) 모드로 사용될 수 있습니다.

2. 용어 정의 (Definitions)

본 매뉴얼에서 공통적으로 사용되는 용어들의 정의입니다.

blank (공백)
스페이스(Space) 또는 탭(Tab) 문자를 의미합니다.
builtin (빌트인)
파일 시스템상의 외부 프로그램이 아니라, 쉘 내부에서 직접 구현된 명령어를 의미합니다. (예: cd, pwd)
control operator (제어 연산자)
제어 기능을 수행하는 토큰입니다. ||, &&, &, ;, |, (, ) 등이 해당됩니다.
exit status (종료 상태)
명령어가 완료된 후 호출자에게 반환하는 값입니다. 0은 성공을, 그 외의 값은 오류를 나타냅니다.
metacharacter (메타 문자)
인용 부호로 감싸지 않았을 때 단어를 구분하는 역할을 하는 문자입니다. |, &, ;, (, ), <, > 및 공백 문자가 포함됩니다.
name (이름/식별자)
문자, 숫자, 밑줄(_)로만 구성되며, 반드시 문자나 밑줄로 시작하는 단어입니다. 변수나 함수 이름으로 사용됩니다.

3. 기본 쉘 기능 (Basic Shell Features)

Bash의 구성 요소인 명령어, 제어 구조, 함수, 파라미터, 확장, 리다이렉션 등에 대해 설명합니다.

3.1 쉘 문법 (Shell Syntax)

쉘이 입력을 읽을 때 처리하는 기본 순서입니다.

  1. 입력 읽기: 파일, 문자열 또는 터미널에서 입력을 읽습니다.
  2. 토큰 분리: 인용 규칙을 적용하여 입력을 단어와 연산자로 분리합니다. 이 과정에서 별칭(Alias) 확장이 일어납니다.
  3. 파싱: 토큰들을 단순 명령어와 복합 명령어로 구조화합니다.
  4. 확장: 각종 쉘 확장(변수 치환, 명령어 실행 등)을 수행합니다.
  5. 리다이렉션: 입출력 방향 지정을 처리합니다.
  6. 실행: 최종 명령어를 실행하고 종료 상태를 기다립니다.

3.1.2 인용 (Quoting)

특정 문자나 단어의 특별한 의미를 제거하여 일반 문자로 취급하도록 하는 기법입니다.

  • 백슬래시 (\): 바로 뒤에 오는 한 문자의 의미를 제거합니다.
  • 작은따옴표 (' '): 감싸진 모든 문자를 문자 그대로 보존합니다. 변수 확장 등이 일어나지 않습니다.
  • 큰따옴표 (" "): $, `, \를 제외한 모든 문자의 의미를 제거합니다. 변수 확장은 허용하면서 공백 등은 보존하고 싶을 때 사용합니다.

3.5 쉘 확장 (Shell Expansions)

명령어가 실행되기 전 텍스트가 변환되는 7가지 단계입니다.

  • Brace Expansion (중괄호 확장): a{b,c}d → abd acd
  • Tilde Expansion (물결표 확장): ~ → 사용자의 홈 디렉토리
  • Parameter Expansion (파라미터/변수 확장): $VARIABLE → 변수 값
  • Command Substitution (명령어 치환): $(command) → 명령어 실행 결과
  • Arithmetic Expansion (산술 확장): $((expression)) → 계산 결과
  • Word Splitting (단어 분할): 확장 결과를 여러 인자로 나눔
  • Filename Expansion (파일 이름 확장): 와일드카드(*, ?) 처리

4. 쉘 빌트인 명령어 (Shell Builtin Commands)

빌트인 명령어는 쉘 프로세스 내부에서 직접 실행되므로 외부 명령어를 실행할 때보다 빠르며, 쉘의 내부 상태를 변경할 수 있습니다.

4.1 주요 빌트인 명령어

cd [-L|[-P [-e]] [-@]] [directory]
현재 디렉토리를 directory로 변경합니다. 디렉토리를 지정하지 않으면 HOME 변수값으로 이동합니다.
echo [-neE] [arg ...]
인자로 주어진 텍스트를 표준 출력으로 내보냅니다. -n 옵션은 마지막 줄바꿈을 생략합니다.
printf [-v var] format [arguments]
형식화된 텍스트를 출력합니다. C 언어의 printf와 유사하며 더 정교한 출력이 가능합니다.
read [-ers] [-a array] [-d delim] [-n nchars] [-p prompt] [-t timeout] [name ...]
표준 입력에서 한 줄을 읽어 변수에 할당합니다.

5. 쉘 변수 (Shell Variables)

Bash는 두 가지 유형의 변수를 사용합니다: 쉘 자체의 동작을 제어하는 쉘 변수와 하위 프로세스로 전달되는 환경 변수입니다.

5.1 주요 Bash 변수

  • BASH_VERSION: 현재 실행 중인 Bash의 버전 정보입니다.
  • IFS: Internal Field Separator. 단어 분할 시 사용하는 구분 문자 목록입니다. (기본값: 공백, 탭, 뉴라인)
  • PATH: 명령어를 찾을 디렉토리 경로의 목록입니다.
  • RANDOM: 0에서 32767 사이의 무작위 정수를 생성합니다.

6. Bash 전용 기능 (Bash Features)

POSIX 표준을 넘어 Bash가 제공하는 강력한 확장 기능들입니다.

6.1 복합 조건문 (Conditional Expressions)

[[ ... ]] 구문을 사용하여 더 안전하고 강력한 조건 검사가 가능합니다. 이 안에서는 변수를 따옴표로 감싸지 않아도 단어 분할이 일어나지 않으며, 패턴 매칭(==, !=)과 정규 표현식 매칭(=~)을 지원합니다.

6.2 산술 연산 (Shell Arithmetic)

(( ... )) 구문을 통해 정수 산술 연산을 수행하고 그 결과에 따라 종료 상태를 반환합니다. let 명령어의 현대적인 대안입니다.

6.3 프로세스 치환 (Process Substitution)

<(list) 또는 >(list) 형태를 사용하여 파이프를 지원하지 않는 명령어에 파이프의 출력을 파일처럼 전달할 수 있습니다. 시스템의 명명된 파이프(FIFO)나 /dev/fd를 활용합니다.

7. 작업 제어 (Job Control)

작업 제어는 프로세스의 실행을 선택적으로 중단(suspend)하고 나중에 다시 재개(resume)할 수 있는 기능을 의미합니다.

7.1 작업 제어의 기초

쉘은 각 파이프라인에 대해 작업(Job)을 할당합니다. 현재 실행 중인 작업 목록은 jobs 명령어로 확인할 수 있습니다.

  • 포그라운드(Foreground): 터미널에서 입력을 직접 받고 신호를 수신하는 프로세스 그룹입니다.
  • 백그라운드(Background): 터미널 제어권 없이 병렬로 실행되는 프로세스 그룹입니다.

작업 참조 방식 (Jobspec)

%n
n번 작업을 참조합니다.
%% 또는 %+
현재 작업(가장 최근에 중단되거나 백그라운드로 전환된 작업)을 참조합니다.
%-
이전 작업을 참조합니다.
%string
명령어 이름이 'string'으로 시작하는 작업을 참조합니다.

7.2 작업 제어 빌트인 명령어

bg [jobspec ...]
중단된 작업을 백그라운드에서 다시 실행합니다.
fg [jobspec]
작업을 포그라운드로 가져와 실행하며 현재 작업으로 만듭니다.
jobs [-lnprs] [jobspec]
현재 활성화된 작업의 상태를 표시합니다. -l 옵션은 프로세스 ID(PID)를 포함합니다.
kill [-s sigspec] [-n signum] [id ...]
특정 프로세스나 작업에 신호(Signal)를 보냅니다. 기본값은 SIGTERM입니다.

8. 명령줄 편집 (Command Line Editing)

Bash는 GNU Readline 라이브러리를 사용하여 강력한 명령줄 편집 기능을 제공합니다.

8.1 편집 표기법

매뉴얼 전반에서 사용되는 단축키 표기 방식입니다:

  • C-k: Control 키를 누른 상태에서 k를 누릅니다.
  • M-k: Meta(보통 Alt 또는 Option) 키를 누른 상태에서 k를 누릅니다. Meta 키가 없는 경우 ESC를 누른 후 k를 누르는 것과 같습니다.

8.2 Readline 상호작용

긴 명령어를 입력하다가 오타를 발견했을 때, 처음부터 다시 입력할 필요 없이 특정 위치로 이동하여 수정할 수 있습니다.

기본 편집 단축키 (Bare Essentials)

C-b / C-f
커서를 한 글자 뒤로/앞으로 이동합니다.
C-a / C-e
커서를 줄의 처음/끝으로 이동합니다.
M-b / M-f
커서를 한 단어 뒤로/앞으로 이동합니다.
DEL / Backspace
커서 왼쪽의 문자를 삭제합니다.
C-d
커서 위치의 문자를 삭제합니다.
C-_ 또는 C-x C-u
마지막 편집 작업을 취소(Undo)합니다.

텍스트 잘라내기와 붙여넣기 (Killing and Yanking)

Killing은 텍스트를 삭제하면서 kill-ring이라는 버퍼에 저장하는 것을 의미합니다. Yanking은 저장된 텍스트를 다시 붙여넣는 기능입니다.

  • C-k: 현재 커서 위치부터 줄 끝까지 삭제(Kill)합니다.
  • M-d: 현재 위치부터 단어 끝까지 삭제합니다.
  • C-y: 마지막으로 삭제된 텍스트를 붙여넣기(Yank)합니다.

8.3 Readline 초기화 파일

Readline은 사용자 홈 디렉토리의 .inputrc 파일을 읽어 설정을 적용합니다. set editing-mode vi와 같은 명령으로 기본 동작을 변경할 수 있습니다.

8.6 프로그래밍 가능한 자동 완성

사용자가 Tab 키를 누를 때 실행될 동작을 명령어별로 정의할 수 있습니다. complete 명령어를 사용하여 특정 명령어에 대한 자동 완성 규칙(compspec)을 지정합니다.

9. 히스토리 대화형 사용 (Using History Interactively)

Bash는 이전에 입력한 명령어들을 목록으로 관리하며, 이를 손쉽게 재사용할 수 있는 기능을 제공합니다.

9.3 히스토리 확장 (History Expansion)

! 문자로 시작하는 특수 구문을 사용하여 과거의 명령어를 현재 줄로 가져옵니다.

!!
바로 이전에 실행한 명령어를 그대로 반복합니다.
!n
히스토리 목록의 n번째 명령어를 실행합니다.
!string
'string'으로 시작하는 가장 최근 명령어를 실행합니다.
^string1^string2^
이전 명령어에서 string1을 string2로 치환하여 실행합니다. (빠른 수정)

단어 지정자 (Word Designators)

  • !$: 이전 명령어의 마지막 인자
  • !^: 이전 명령어의 첫 번째 인자
  • !*: 이전 명령어의 모든 인자 (명령어 제외)

10. Bash 설치 (Installing Bash)

Bash는 소스 코드를 통해 다양한 유닉스 계열 시스템에서 빌드하고 설치할 수 있습니다.

  1. ./configure: 시스템 환경을 분석하고 Makefile을 생성합니다.
  2. make: 소스 코드를 컴파일합니다.
  3. make install: 생성된 바이너리와 매뉴얼을 시스템 경로에 설치합니다.
